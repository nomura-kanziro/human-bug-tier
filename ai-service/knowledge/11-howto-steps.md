# 단계별 사용법

## 나만의 티어표 만드는 순서

1. 메뉴 "커스텀 메이커 → 제작하기"로 들어가요.
2. 아래 "전체 캐릭터 풀"에서 캐릭터를 찾아요(위쪽 검색창에 이름을 넣어도 돼요).
3. PC는 캐릭터를 끌어서 등급 칸에 놓고, 모바일은 캐릭터를 탭한 뒤 넣을 등급 칸을 탭해요. Ctrl(맥은 ⌘)을 누른 채 클릭하면 여러 명을 한꺼번에 옮겨요.
4. 표 위쪽 버튼으로 1~9등급을 넘겨 가며 계속 배치해요.
5. 필요하면 "꾸미기"로 색과 이펙트를 입혀요.
6. "다운로드"로 PNG, PDF, JSON 저장하거나, "업로드"로 게시판에 올려요.

## 티어표를 게시판에 올리는 순서

1. 제작 화면에서 티어표를 완성해요.
2. 아래 "업로드" 버튼을 눌러요(로그인이 필요해요).
3. 제목과 내용을 적고, 썸네일 이미지를 정해요.
4. 등록하면 게시판에 올라가고, 마이페이지의 "내가 쓴 게시글"에서도 볼 수 있어요.

## 꾸미기 하는 순서

1. 제작 화면에서 "꾸미기"를 눌러요.
2. 적용 범위를 "이 등급만"이나 "모든 등급"으로 정해요. "등급마다 다른 테마"를 누르면 1~9등급에 서로 다른 테마가 한 번에 입혀져요.
3. 빠른 테마 중에서 고르거나, 테두리 색과 배경 이펙트를 따로 골라요.
4. 이펙트를 골랐다면 "이펙트 색"에서 기본색, 스와치, 직접 선택 중 하나로 빛 색을 바꿔요.
5. 마음에 안 들면 "원래 상태로 돌려놓기"로 모두 지워요.

## 행운 티어 포커 하는 순서

1. 메뉴 "행운 뽑기 → 행운 티어 포커"로 들어가요(로그인 필요).
2. 걸 포인트를 정해요. 배팅액은 정하는 순간 먼저 빠져요.
3. 공개된 후보 카드 5장 중에서 3장을 골라요.
4. 미리 정해진 2장이 붙어 5장이 되고 딜러와 족보를 비교해 승패가 나와요.
5. 이기면 원금과 배팅액 × 족보 배수를 받고, 같으면 원금을 돌려받고, 지면 배팅액을 잃어요.

## 랜덤 뽑기에 배팅하는 순서

1. 메뉴 "행운 뽑기 → 랜덤 뽑기"로 들어가요(배팅은 로그인 필요).
2. 지금 열려 있는 라운드를 확인해요. 라운드는 5분마다 자동으로 마감돼요.
3. 배팅 종류(묶음 티어, 홀짝 티어, 티어 지목)와 포인트를 정해 배팅해요. 한 라운드에 한 번만 할 수 있어요.
4. 마감되면 결과 캐릭터가 공개되고, 이기면 배팅액 × 배수만큼 더해지고 지면 배팅액만큼 빠져요.

## 매일 퀴즈 푸는 순서

1. 메뉴 "이벤트 → 매일 간단 퀴즈"로 들어가요(로그인 필요).
2. 오늘의 문제("이 캐릭터는 어느 티어인가요?")의 보기 3개 중 하나를 골라요.
3. "정답 제출하기"를 누르면 채점돼요.
4. 맞히면 1~1000포인트를 복권식으로 받아요. 하루에 한 번만 풀 수 있어요.

## 이벤트 티어표 공개에 참가하는 순서

1. 메뉴 "이벤트 → 티어표 공개"에서 진행 중인 회차를 확인해요(운영진이 회차를 열어야 해요).
2. 이미 게시판에 올린 내 글로 참가하거나, "새로 만들어서 참가"로 제작 화면에서 티어표를 만들어 업로드해요.
3. 접수가 끝나면 다른 사람의 작품에 투표할 수 있어요. 한 회차에 한 표예요.
4. 결과 공개 시각에 우승자가 발표되고 상금이 지급돼요.

## 닉네임 바꾸는 순서

1. 헤더의 프로필 사진 → 마이페이지로 들어가요.
2. 프로필 영역의 "닉네임 변경"을 눌러요.
3. 새 닉네임을 넣어요. 2~20자, 한글·영문·숫자와 _ - . 만 쓸 수 있고 공백과 @는 안 돼요.
4. 확인하면 바뀌고, 7일에 한 번만 바꿀 수 있어요. 바뀐 닉네임이 새 로그인 아이디가 돼요.

## 프로필 사진 바꾸는 순서

1. 마이페이지의 "사진 변경"을 눌러요(헤더 프로필 메뉴에도 있어요).
2. 사진 파일을 고르면 가운데를 정사각형으로 잘라 저장돼요.
3. 사진은 이 브라우저에만 저장되고, 기본 이미지로 되돌리려면 "기본 이미지로"를 눌러요.

## 비밀번호 재설정 순서

1. 로그인 화면에서 아이디·비밀번호 찾기로 들어가요.
2. 가입한 메일 주소를 넣고 재설정 메일을 받아요.
3. 메일의 "비밀번호 재설정하기" 버튼을 눌러 1시간 안에 새 비밀번호를 정해요.

## 문의 남기는 순서

1. 푸터의 "문의하기"로 들어가요(로그인 필요).
2. 제목과 내용을 적고 "등록하기"를 눌러요.
3. 운영진이 답변하면 알림(🔔)이 와요. 내 문의는 수정하거나 삭제할 수 있어요.

## 홈 화면에 사이트 추가하는 방법

1. 안드로이드 크롬은 메뉴에서 "홈 화면에 추가"나 "앱 설치"를 눌러요.
2. 아이폰 사파리는 공유 버튼에서 "홈 화면에 추가"를 눌러요.
3. 홈 화면의 아이콘으로 앱처럼 열 수 있어요.
