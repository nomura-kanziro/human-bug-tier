## 할 수 있는 작업

| 작업 | 강도 | 예시 요청 | 결과물 |
|---|---|---|---|
| 티어표 초안 만들기 | 무거움 | "1~3티어 캐릭터로 티어표 만들어줘. 츠루기 시노부는 2티어로 옮기고" | 커스텀 메이커에 바로 올릴 수 있는 배치 + "커스텀 메이커에서 열기" |
| 내 티어표 분석 | 보통 | "지금 만들고 있는 티어표 공식이랑 비교해줘" | 일치율 · 공식보다 높게/낮게 둔 캐릭터 · 티어별 인원 |
| 게시판 · 공지 요약 | 보통 | "요즘 인기 있는 티어표 정리해줘" | 추천 많은 글 · 최근 글 · 최근 공지(링크) |
| 내 활동 브리핑 | 보통 | "내 포인트랑 출석 현황 브리핑해줘" | 포인트 · 출석 · 뽑기 · 내 글 카드 + 오늘 할 만한 일 |
| 사이트 통합 검색 | 가벼움 | "이름에 '류'가 들어가는 캐릭터 찾아줘" | 캐릭터 · 게시글 · 공지 목록(링크) — LLM 을 쓰지 않아 토큰 0 |

강도는 "얼마나 큰 일인지" 표시용이다. 요금은 강도가 아니라 **고른 엔진**으로 정해진다(2026-11-17 변경 — 그 전에는 행운 뽑기 포인트를 강도별 2·4·8P 차감했다).

## 엔진과 요금 (2026-11-17~)

| 엔진 | 모델 | 요금 |
|---|---|---|
| **무료 엔진** | 서버의 Ollama `gemma4:e4b`(가이드 챗봇과 같은 모델) | 토큰 없이 **하루(KST) 20번** — `FREE_DAILY_LIMIT` |
| **Claude 엔진** | 회원이 고른 Claude 모델 + effort | **휴버토큰**(AI 전용 포인트) 정액 차감 |

**휴버토큰 요금표** — 값의 정본은 `backend/utils/aiTokens.js`. 1토큰 ≈ $0.001. "평균 한 번"을 입력 2,500토큰 + 출력 700토큰(effort medium)으로 보고 모델 API 가격으로 계산해 올림했다.

| 모델 | API 가격(입력/출력, $/1M) | 평균값 | small ×0.6 | medium ×1 | high ×1.6 | extra high ×2.4 |
|---|---|---:|---:|---:|---:|---:|
| Haiku 5.5 | 0.10 / 0.50 | 1 | 1 | 1 | 2 | 3 |
| Haiku 4.5 | 1 / 5 | 6 | — | 6 | — | — |
| Sonnet 5.5 | 2 / 10 | 12 | 8 | 12 | 20 | 29 |
| Sonnet 5.0 | 2 / 10 | 12 | 8 | 12 | 20 | 29 |
| Opus 5.5 | 4 / 20 | 24 | 15 | 24 | 39 | 58 |
| Opus 5.0 | 5 / 25 | 30 | 18 | 30 | 48 | 72 |
| Fable 5.2 | 8 / 40 | 48 | 29 | 48 | 77 | 116 |
| Fable 5.1 | 10 / 50 | 60 | 36 | 60 | 96 | 144 |

effort(small·medium·high·extra high)는 Claude API 의 `output_config.effort`(low·medium·high·xhigh)다. Haiku 4.5 는 effort 를 지원하지 않아 고를 수 없다(항상 6).

요금 규칙:

- 어떤 작업인지 정해지는 순간(`plan` 이벤트) 받는다 — Claude 엔진은 휴버토큰 차감, 무료 엔진은 오늘 횟수 1회. 모자라면 받지 않고 안내한다(시작 전에 한 번 더 미리 거른다).
- 이용법 질문 · 거절 · 못 알아들은 말 · 분석할 티어표가 없을 때는 **횟수도 토큰도 들지 않는다**. LLM 을 쓰지 않는 통합 검색은 Claude 엔진을 골라도 **무료 횟수 1회**만 쓴다.
- 작업이 실패하면(도구 오류 · 중간 끊김 · 시간 초과) **되돌려 준다**(휴버토큰 환불 · 무료 횟수 되돌림). 사용자가 직접 중지하거나 탭을 닫은 경우는 되돌리지 않는다.
- **끊기지 않게**: Claude 가 해설을 못 쓰면(키 없음 · API 오류 · 거절) 무료 엔진이 이어서 쓰고, 그것도 안 되면 정해진 해설로 끝까지 간다. 이때 받은 휴버토큰은 돌려준다(`engine_used ≠ claude`).
- 회원 한 명당 10분에 12번, 동시에 한 작업. 요청은 500자까지.
- 행운 뽑기 포인트는 더 이상 쓰지 않는다. 2026-11-17 전의 사용 내역은 행운 포인트 원장(`LuckPointLog` source `agent_bot`)에 남아 있다.

## 휴버토큰

- AI 전용 포인트. 지갑 `AiTokenWallet`(회원당 1개, 처음 만들 때 **500** 지급 + 무료 엔진 하루 횟수), 원장 `AiTokenLog`(기본 지급 · 사용 · 환불 · 구매 승인 · 후원 승인 · 관리자 지급), 충전 신청 `AiTokenOrder`.
- **충전**: 사이트에 결제 대행(PG)이 없어 "신청 → 운영자 확인 → 승인 시 적립" 방식이다.
  - 구매 신청 묶음: 1,000토큰 2,000원 · 3,000토큰 5,500원 · 10,000토큰 17,000원(`TOKEN_PACKS`).
  - 후원 확인 신청: 후원 페이지(헤더 커피 버튼과 같은 주소)에서 후원 → 이름·금액을 남김 → 운영자가 적립할 토큰 수를 정해 승인.
  - 대기 신청은 회원당 3건. 신청 화면에는 확인용 메모(입금자명 등)만 받고 카드·계좌 번호는 받지 않는다.
  - 결제 방법 안내 한 줄은 서버 환경 변수 `AI_TOKEN_PAY_GUIDE`(비우면 "문의하기로 안내").
- **관리자**: 대시보드 "🪙 휴버토큰 관리" — 신청 목록(대기·승인·거절), 적립 토큰을 정해 승인/거절(대기일 때만 한 번), 닉네임으로 직접 지급·회수.
- API: `GET /api/ai/tokens`(내 지갑·원장·신청·묶음) · `POST /api/ai/tokens/orders` · 관리자 `GET /api/admin/ai-tokens/orders` · `POST …/orders/:id/approve|reject` · `POST /api/admin/ai-tokens/grant`.

### 티어표 초안 만들기에서 말로 정할 수 있는 것

| 말 | 동작 |
|---|---|
| "1~3티어", "2티어 5티어", "상위권/중위권/하위권" | 공식 티어표에서 가져올 범위 |
| "A는 2티어로", "A랑 B를 3티어 을급으로" | 캐릭터 옮기기(세부등급을 안 말하면 원래 세부등급 유지, 그 티어에 없으면 맨 아래 칸) |
| "A 한 단계 올려줘", "A 두 단계 내려서" | 티어 올리기·내리기(1~9 범위 안에서) |
| "A는 빼줘" | 제외 |
| "랜덤으로", "섞어서" | 고른 캐릭터를 무작위로 다시 배치(칸별 인원 수는 유지) |
| "A, B, C 만으로" | 그 캐릭터만 공식 위치에 |
| `"제목"`, "제목은 ○○로" | 초안 제목 |

캐릭터는 공식 티어표(`tiers.json`)에 있는 이름만 넣는다. 이름·배치·숫자는 전부 도구가 계산하고 LLM 은 해설만 쓴다.

## 평가 — 넣은 기능과 뺀 기능

| 후보 | 판단 | 이유 |
|---|---|---|
| 프롬프트로 티어표 초안 만들기 | ✅ 적용 | 300명이 넘는 캐릭터를 하나씩 끌어다 놓는 수고를 줄인다. 가이드 챗봇에 없는 기능 |
| 내 티어표 분석 | ✅ 적용 | 내 배치를 아는 건 에이전트 봇뿐(가이드 챗봇은 화면 상태를 모른다) |
| 게시판 · 공지 요약 | ✅ 적용 | 가이드 챗봇은 실제 글·공지를 모른다(지식 문서만 읽는다) |
| 내 활동 브리핑 | ✅ 적용 | 가이드 챗봇은 로그인 정보를 몰라 규칙만 설명한다 |
| 통합 검색 | ✅ 적용(차별화) | 캐릭터 한 명의 티어 질문은 가이드 챗봇과 겹친다 → 조건으로 여러 명을 목록으로 뽑고, 게시판·공지의 실제 글까지 한 번에 찾는 쪽으로 차별화 |
| 사이트 이용법 설명 | ❌ 제외 | 가이드 챗봇과 완전히 겹친다 → 무료로 `/ai` 를 안내 |
| 게시글·댓글·추천 대리 작성 | ❌ 제외 | 쓰기 대행은 오남용(도배·조작) 위험이 크다. 초안은 사용자가 커스텀 메이커에서 확인하고 직접 올린다 |
| 행운 뽑기·포커 대리 실행 | ❌ 제외 | 포인트가 걸린 게임을 자동으로 돌리는 건 취지에 맞지 않는다 |

## 구조

```
브라우저(AgentBot.jsx) ──POST /api/ai/agent/run──▶ Express(aiAgentController.js) ──POST /agent/run──▶ ai-service(app/Agent-Bot)
        ▲   NDJSON 이벤트 스트림                      │ 회원 확인·제한·휴버토큰/무료 횟수·환불              │ plan → 도구 → 해설(고른 엔진 스트리밍)
        └──────────────────────────────────────────────┘                                                   │
                                                     ◀──GET /api/ai/agent/data/posts|notices──────────────┘ (도구가 게시판·공지 조회)
```

- **ai-service** `app/Agent-Bot/` — LangGraph 로 `plan → 도구 노드`. 작업 판별은 규칙이 먼저(0초)이고 애매한 말만 LLM 에 JSON 으로 묻는다. 도구는 계산·조회만 하고, 결과물을 먼저 내보낸 뒤 해설을 LLM 이 스트리밍으로 쓴다.
- **Express** — 회원(관리자 아님) 확인, 요청 수 제한, 엔진 선택 검사, 회원 현재 상태 조회 후 전달(로그인 토큰·이메일은 넘기지 않음), 휴버토큰 차감·무료 횟수·환불·원장, 스트림 전달, 15초 ping.
- **화면** — 상태를 라우트 바깥 `AgentBotContext` 에 두어 모달을 닫거나 페이지를 옮겨도 작업이 계속된다.

이벤트(한 줄에 JSON 하나): `plan`(작업·강도·엔진·받은 값 `unit`=token|free|none) → `step`(진행) → `result`(결과물) → `token`(해설 글자) → `done`(`engine_used`, Claude 실패 시 환불 정보) / `error`(환불 정보 포함) · `reset`(쓰다 만 해설 지움) · `ping`(연결 유지).

## 느려지지 않게 한 것

| 무엇 | 어떻게 |
|---|---|
| 작업 판별 | 규칙으로 먼저 정해 LLM 을 부르지 않는다. 못 정한 말만 짧은 JSON(120토큰)으로 묻는다 |
| 첫 화면 | 결과물(계산)이 해설보다 먼저 나간다 — 로컬 실측 0.1초 안 |
| 해설 | 스트리밍 + 짧은 길이(`AGENT_SUMMARY_TOKENS`, 기본 260). 검색은 LLM 해설 없이 바로 끝낸다 |
| 모델 적재 | 가이드 챗봇과 같은 모델·같은 `num_ctx` 를 써서 다시 올리지 않는다. 생각 모드 끔 |
| AI 서버 OFF | LLM 을 기다리지 않고 도구가 만든 정해진 해설로 끝낸다 |
| Claude 엔진 | 공식 SDK 스트리밍, 분류는 가장 낮은 effort. 실패하면 무료 엔진 → 정해진 해설로 이어서 끊기지 않는다 |
| 화면 | 글자를 ref 에 모아 프레임마다 한 번에 반영, 메시지는 memo 로 마지막 것만 다시 그린다 |
| 중간 프록시 | `X-Accel-Buffering: no`, nginx 전용 location(버퍼링 끔), 15초 ping |

로컬 실측(RTX 4070 SUPER, `gemma4:e4b`): 결과물 0.05~0.25초, 해설 첫 글자 0.2~0.5초, 전체 3~5.5초, LLM 작업 판별 0.9초.
운영 서버는 CPU(약 6토큰/초)라 해설이 이보다 훨씬 느리다 — 결과물은 바로 나오고 해설이 천천히 이어진다.

## 화면

- 오른쪽 아래 원형 버튼(로고 + 로봇 표식). 작업 중에는 고리가 돌고 "작업 중…", 끝나면 "작업 완료 ✓".
- 모달 왼쪽: **엔진 고르기**(무료 엔진 오늘 남은 횟수 / Claude 엔진 — 모델 select · effort 4단계 · 한 번에 드는 토큰) → 작업 목록 → 요금 규칙(좁은 화면에서는 접힘). 헤더: 무료 엔진 상태·🪙 휴버토큰 잔액(누르면 충전 패널).
- 충전 패널: 잔액 · 모델×effort 요금표 · 묶음 구매 신청 · 후원 확인 신청 · 내 신청 상태 · 최근 원장. 고른 엔진은 이 기기에 기억한다(`hbtAgentEngine`).
- 모달을 닫거나 다른 페이지로 가도 작업은 계속된다. 탭을 닫거나 새로고침하면 멈춘다.
- 대화는 이 탭(sessionStorage)에만 남고 서버에 저장하지 않는다. 로그아웃하면 지운다.
- 버튼을 띄우지 않는 곳: 로그인·회원가입·아이디 찾기·비밀번호 재설정·관리자 화면, 가이드 모드가 켜진 동안.
- 비로그인은 로그인 안내, 관리자 계정은 "회원 계정으로만" 안내가 보인다.

| | `ANTHROPIC_API_KEY` | 채우면 Claude 엔진이 켜진다(비우면 Claude 를 골라도 무료 엔진으로 처리하고 토큰은 받지 않음) |
| `backend/.env` | `AI_AGENT_TIMEOUT_MS` | 작업 하나의 최대 시간(기본 5분). 넘으면 끊고 환불 |
| | `AI_TOKEN_PAY_GUIDE` | 충전 신청 화면의 결제·후원 방법 안내 한 줄 |
| | `AI_SERVICE_URL` · `AI_SERVICE_KEY` | 가이드 챗봇과 공용 |

## 운영 반영

1. `bash backend/deploy/oracle/deploy.sh deploy` — 사이트와 ai-service 가 함께 올라간다(새 의존성 없음).
2. 서버 nginx 설정에 `/api/ai/agent/run` location 을 추가한다(저장소 `backend/deploy/oracle/nginx-human-bug-tier.conf` 의 블록 — 버퍼링 끔, 330초). certbot 이 고친 서버 설정을 덮어쓰지 않게 **손으로 추가**하고 `nginx -t && systemctl reload nginx`.
3. 서버가 CPU 라 해설이 길면 느리다. `shared/ai.env` 에 `AGENT_SUMMARY_TOKENS=120` 정도로 줄이는 것을 권한다.
4. 반영 뒤 회원 계정으로 오른쪽 아래 버튼 → 무료 엔진으로 검색 한 번(오늘 남은 횟수가 줄어드는지), Claude 엔진(Haiku 5.5 · small = 1토큰)으로 초안 한 번, 관리자 "휴버토큰 관리"에서 신청 승인이 되는지 확인.
5. (2026-11-17 변경분) Claude 엔진을 켜려면 서버 `shared/ai.env` 에 `ANTHROPIC_API_KEY` 를 **서버에서 직접** 입력하고 `hbt-ai` 재시작. 결제 안내 문구는 `shared/.env` 의 `AI_TOKEN_PAY_GUIDE`.
