## 할 수 있는 작업과 요금

| 작업 | 강도 | 포인트 | 예시 요청 | 결과물 |
|---|---|---|---|---|
| 티어표 초안 만들기 | 무거움 | 8P | "1~3티어 캐릭터로 티어표 만들어줘. 츠루기 시노부는 2티어로 옮기고" | 커스텀 메이커에 바로 올릴 수 있는 배치 + "커스텀 메이커에서 열기" |
| 내 티어표 분석 | 보통 | 4P | "지금 만들고 있는 티어표 공식이랑 비교해줘" | 일치율 · 공식보다 높게/낮게 둔 캐릭터 · 티어별 인원 |
| 게시판 · 공지 요약 | 보통 | 4P | "요즘 인기 있는 티어표 정리해줘" | 추천 많은 글 · 최근 글 · 최근 공지(링크) |
| 내 활동 브리핑 | 보통 | 4P | "내 포인트랑 출석 현황 브리핑해줘" | 포인트 · 출석 · 뽑기 · 내 글 카드 + 오늘 할 만한 일 |
| 사이트 통합 검색 | 가벼움 | 2P | "이름에 '류'가 들어가는 캐릭터 찾아줘" | 캐릭터 · 게시글 · 공지 목록(링크) |

요금 규칙(값의 정본은 `backend/controllers/aiAgentController.js` 의 `AGENT_COSTS`):

- 어떤 작업인지 정해지는 순간(`plan` 이벤트) 차감한다. 잔액이 모자라면 차감 없이 안내한다.
- 이용법 질문 · 거절 · 못 알아들은 말 · 분석할 티어표가 없을 때는 **무료**다.
- 작업이 실패하면(도구 오류 · 중간 끊김 · 시간 초과) **환불**한다. 사용자가 직접 중지하거나 탭을 닫은 경우는 환불하지 않는다.
- AI 서버(LLM)가 OFF 면 AI 해설 없이 결과만 나오므로 어떤 작업이든 **가벼움 요금(2P)** 만 받는다.
- 회원 한 명당 10분에 12번, 동시에 한 작업. 요청은 500자까지.
- 포인트 증감은 원장(`LuckPointLog`, source `agent_bot`)에 남고 관리자 "행운 뽑기 관리 → 포인트 내역"에 "에이전트 봇"으로 보인다.

### 티어표 초안 만들기에서 말로 정할 수 있는 것

| 말 | 동작 |
|---|---|
| "1~3티어", "2티어 5티어", "상위권/중위권/하위권" | 공식 티어표에서 가져올 범위 |
| "A는 2티어로", "A랑 B를 3티어 을급으로" | 캐릭터 옮기기(세부등급을 안 말하면 원래 세부등급 유지, 그 티어에 없으면 맨 아래 칸) |
| "A 한 단계 올려줘", "A 두 단계 내려서" | 티어 올리기·내리기(1~9 범위 안에서) |
| "A는 빼줘" | 제외 |
| "랜덤으로", "섞어서" | 고른 캐릭터를 무작위로 다시 배치(칸별 인원 수는 유지) |
| "A, B, C 만으로" | 그 캐릭터만 공식 위치에 |
| `"제목"`, "제목은 ○○로" | 초안 제목 |

캐릭터는 공식 티어표(`tiers.json`)에 있는 이름만 넣는다. 이름·배치·숫자는 전부 도구가 계산하고 LLM 은 해설만 쓴다.

## 평가 — 넣은 기능과 뺀 기능

| 후보 | 판단 | 이유 |
|---|---|---|
| 프롬프트로 티어표 초안 만들기 | ✅ 적용 | 300명이 넘는 캐릭터를 하나씩 끌어다 놓는 수고를 줄인다. 가이드 챗봇에 없는 기능 |
| 내 티어표 분석 | ✅ 적용 | 내 배치를 아는 건 에이전트 봇뿐(가이드 챗봇은 화면 상태를 모른다) |
| 게시판 · 공지 요약 | ✅ 적용 | 가이드 챗봇은 실제 글·공지를 모른다(지식 문서만 읽는다) |
| 내 활동 브리핑 | ✅ 적용 | 가이드 챗봇은 로그인 정보를 몰라 규칙만 설명한다 |
| 통합 검색 | ✅ 적용(차별화) | 캐릭터 한 명의 티어 질문은 가이드 챗봇과 겹친다 → 조건으로 여러 명을 목록으로 뽑고, 게시판·공지의 실제 글까지 한 번에 찾는 쪽으로 차별화 |
| 사이트 이용법 설명 | ❌ 제외 | 가이드 챗봇과 완전히 겹친다 → 무료로 `/ai` 를 안내 |
| 게시글·댓글·추천 대리 작성 | ❌ 제외 | 쓰기 대행은 오남용(도배·조작) 위험이 크다. 초안은 사용자가 커스텀 메이커에서 확인하고 직접 올린다 |
| 행운 뽑기·포커 대리 실행 | ❌ 제외 | 포인트가 걸린 게임을 자동으로 돌리는 건 취지에 맞지 않는다 |

## 구조

```
브라우저(AgentBot.jsx) ──POST /api/ai/agent/run──▶ Express(aiAgentController.js) ──POST /agent/run──▶ ai-service(app/Agent-Bot)
        ▲   NDJSON 이벤트 스트림                      │ 회원 확인·제한·포인트 차감/환불                    │ plan → 도구 → 해설(LLM 스트리밍)
        └──────────────────────────────────────────────┘                                                   │
                                                     ◀──GET /api/ai/agent/data/posts|notices──────────────┘ (도구가 게시판·공지 조회)
```

- **ai-service** `app/Agent-Bot/` — LangGraph 로 `plan → 도구 노드`. 작업 판별은 규칙이 먼저(0초)이고 애매한 말만 LLM 에 JSON 으로 묻는다. 도구는 계산·조회만 하고, 결과물을 먼저 내보낸 뒤 해설을 LLM 이 스트리밍으로 쓴다.
- **Express** — 회원(관리자 아님) 확인, 요청 수 제한, 회원 현재 상태 조회 후 전달(토큰·이메일은 넘기지 않음), 포인트 차감·환불·원장, 스트림 전달, 15초 ping.
- **화면** — 상태를 라우트 바깥 `AgentBotContext` 에 두어 모달을 닫거나 페이지를 옮겨도 작업이 계속된다.

이벤트(한 줄에 JSON 하나): `plan`(작업·강도·차감 포인트) → `step`(진행) → `result`(결과물) → `token`(해설 글자) → `done` / `error`(환불 정보 포함) · `reset`(쓰다 만 해설 지움) · `ping`(연결 유지).

## 느려지지 않게 한 것

| 무엇 | 어떻게 |
|---|---|
| 작업 판별 | 규칙으로 먼저 정해 LLM 을 부르지 않는다. 못 정한 말만 짧은 JSON(120토큰)으로 묻는다 |
| 첫 화면 | 결과물(계산)이 해설보다 먼저 나간다 — 로컬 실측 0.1초 안 |
| 해설 | 스트리밍 + 짧은 길이(`AGENT_SUMMARY_TOKENS`, 기본 260). 검색은 LLM 해설 없이 바로 끝낸다 |
| 모델 적재 | 가이드 챗봇과 같은 모델·같은 `num_ctx` 를 써서 다시 올리지 않는다. 생각 모드 끔 |
| AI 서버 OFF | LLM 을 기다리지 않고 도구가 만든 정해진 해설로 끝낸다 |
| 화면 | 글자를 ref 에 모아 프레임마다 한 번에 반영, 메시지는 memo 로 마지막 것만 다시 그린다 |
| 중간 프록시 | `X-Accel-Buffering: no`, nginx 전용 location(버퍼링 끔), 15초 ping |

로컬 실측(RTX 4070 SUPER, `gemma4:e4b`): 결과물 0.05~0.25초, 해설 첫 글자 0.2~0.5초, 전체 3~5.5초, LLM 작업 판별 0.9초.
운영 서버는 CPU(약 6토큰/초)라 해설이 이보다 훨씬 느리다 — 결과물은 바로 나오고 해설이 천천히 이어진다.

## 화면

- 오른쪽 아래 원형 버튼(로고 + 로봇 표식). 작업 중에는 고리가 돌고 "작업 중…", 끝나면 "작업 완료 ✓".
- 모달 왼쪽: 작업 목록·요금·포인트 규칙(좁은 화면에서는 위로 올라가고 규칙은 접힘). 헤더: AI 서버 상태·보유 포인트.
- 모달을 닫거나 다른 페이지로 가도 작업은 계속된다. 탭을 닫거나 새로고침하면 멈춘다.
- 대화는 이 탭(sessionStorage)에만 남고 서버에 저장하지 않는다. 로그아웃하면 지운다.
- 버튼을 띄우지 않는 곳: 로그인·회원가입·아이디 찾기·비밀번호 재설정·관리자 화면, 가이드 모드가 켜진 동안.
- 비로그인은 로그인 안내, 관리자 계정은 "회원 계정으로만" 안내가 보인다.

## 운영 반영

1. `bash backend/deploy/oracle/deploy.sh deploy` — 사이트와 ai-service 가 함께 올라간다(새 의존성 없음).
2. 서버 nginx 설정에 `/api/ai/agent/run` location 을 추가한다(저장소 `backend/deploy/oracle/nginx-human-bug-tier.conf` 의 블록 — 버퍼링 끔, 330초). certbot 이 고친 서버 설정을 덮어쓰지 않게 **손으로 추가**하고 `nginx -t && systemctl reload nginx`.
3. 서버가 CPU 라 해설이 길면 느리다. `shared/ai.env` 에 `AGENT_SUMMARY_TOKENS=120` 정도로 줄이는 것을 권한다.
4. 반영 뒤 회원 계정으로 오른쪽 아래 버튼 → 검색(2P) 한 번, 티어표 초안(8P) 한 번, 관리자 포인트 내역에 "에이전트 봇"이 남는지 확인.

## 확인한 것 · 못 한 것

- pytest 85개 통과(에이전트 봇 31개 — 가짜 LLM·가짜 조회 API).
- 실제 `gemma4:e4b` 로 5개 작업 + LLM 작업 판별 + 범위 밖 말을 돌려 봤다.
- 격리 포트에서 임시 회원으로 포인트 차감(8·4·4·2P)·잔액 부족·환불(오류 이벤트·끊김)·AI OFF 요금(2P)을 원장으로 확인하고 임시 회원을 지웠다.
- 가짜 API + 헤드리스 크롬으로 PC·모바일·다크·비로그인 화면과 "닫고 다른 페이지로 가도 계속 → 완료 → 커스텀 메이커 반영"을 확인했다.
- **못 한 것**: 운영 서버(CPU·Cloudflare·nginx 경유)에서의 스트림 동작과 속도, Claude API(`anthropic`)로 돌렸을 때의 답 품질.
