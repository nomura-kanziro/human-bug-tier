# 커밋 요약 — 관리자 페이지 "이벤트 관리": 메모리 기록 이벤트를 관리자가 열고 티어표 공개 관리를 이전

백엔드 기록: [`../../backend/09-event/02-memory-period-record.md`](../../backend/09-event/02-memory-period-record.md)

> ⚠ **후속 변경**: 아래 "제작한 티어표 공개(뼈대)" 관리 폼과 "준비 중" 탭은 이후 **정식 오픈**으로 바뀌었다(회원 출품·투표, 관리자 접수 시작 예약·우승작 선정).
> → [03-showcase-launch-record.md](./03-showcase-launch-record.md)

## 요청

> 티어표 공개 같은 건 관리자 전용 페이지에서 관리하고, 메모리 게임 기록 이벤트도 관리자 페이지에서 관리자가 직접 열 수 있도록.

## 1. 이벤트 관리 섹션 (관리자 대시보드 `/admin`)

`AdminDashboard` 에 **"🎉 이벤트 관리"** 섹션(`AdminEventManager.jsx`, 앵커 `#admin-events`)을 추가했다.
모든 요청은 `adminRequest`(관리자 토큰) → 서버 `requireAdmin` 이다.

### 메모리 게임 기록 이벤트

- 폼: 제목 · 설명(선택) · **1위 상금(1000P 이상)** · 자동 마감 시각(선택)
- 버튼: **작성 중으로 저장** / **저장하고 바로 열기**(다른 회차가 열려 있으면 비활성) / 수정 저장·취소
- 목록(최근 10건): 제목 · 상태 배지(작성 중/진행 중/마감·정산 대기/정산 완료) · 상금 · 자동 마감 · 참가자 수 · 1위,
  그리고 상태에 맞는 조작만 보인다.

| 상태 | 보이는 버튼 |
|------|-------------|
| 작성 중 | 수정 · **열기** · 삭제 |
| 진행 중 | 수정 · **닫기** · **정산** |
| 마감·정산 대기 | **정산** |
| 정산 완료 | 없음 |

- 열기/닫기/정산/삭제는 **확인창**을 거친다(정산은 "1위에게 상금이 지급되고 알림이 발송됩니다. 되돌릴 수 없습니다").
- 정산하면 "1위 OOO (21.50초)에게 1500P 를 지급하고 알림을 보냈습니다" 처럼 결과를 화면에 남긴다.
- 상금을 999P 등으로 넣으면 서버 오류 메시지("1000P 이상의 정수")가 그대로 표시된다.

### 제작한 티어표 공개 (뼈대 · 정식 공개 전)

이벤트 페이지에 있던 관리 폼을 **이 섹션으로 옮겼다**: 제목·설명·접수 마감·결과 공개(기본 마감+30분) 입력,
저장 / 접수 열기 / 접수 닫기 / 지금 결과 발표(참가자 전원 알림), 참가 목록. 발표가 끝난 회차는 입력을 잠그고 **[새 회차 만들기]** 를 보여 준다.

## 2. 이벤트 페이지(`/event`)는 회원용 화면만

- **티어표 공개 탭**: 관리자 여부와 상관없이 "준비 중" 안내만 보인다. 관리자에게만 "관리자 페이지 → 이벤트 관리" 링크
  (`/admin#admin-events`)를 덧붙인다. 정식 오픈은 이 자리에 회원용 참가 화면을 붙이면 된다.
- **메모리 게임 탭**: 기록 이벤트 상태 카드를 게임 위에 보여 준다 — 진행 중이면 제목·1위 상금·마감 시각·설명, 없으면
  "지금은 진행 중인 기록 이벤트가 없어 게임을 할 수 없습니다". 열려 있지 않으면 시작 버튼이 **"진행 중인 이벤트 없음"** 으로 비활성이고,
  마감/정산된 회차는 **최종 순위와 우승자**를 보여 준다. 플레이 도중 이벤트가 닫히면 서버 메시지를 띄우고 현황을 새로 불러온다.
- 표시용 유틸(`toLocalInput`/`formatWhen`/`formatMs`)은 `lib/eventFormat.js` 로 모아 이벤트 페이지와 관리 화면이 함께 쓴다.

## 주요 파일

| 파일 | 내용 |
|------|------|
| `root-cloudflare/src/components/AdminEventManager.jsx` | 신규 — 관리자 이벤트 관리(기록 이벤트 + 티어표 공개) |
| `root-cloudflare/src/styles/admin-event.css` | 신규 — 관리 화면 스타일(테마 토큰 → 라이트/다크 자동, 모바일은 표를 가로 스크롤) |
| `root-cloudflare/src/lib/eventFormat.js` | 신규 — 시각·기록 표시 유틸 |
| `root-cloudflare/src/pages/AdminDashboard.jsx` | 섹션 연결 |
| `root-cloudflare/src/components/EventShowcasePanel.jsx` | 관리 폼 제거 → "준비 중" + 관리자 안내 링크 |
| `root-cloudflare/src/components/EventMemoryPanel.jsx` | 기록 이벤트 상태 카드 · 열려 있지 않으면 비활성 · 순위 제목 |
| `root-cloudflare/src/styles/event.css` | 상태 카드·관리자 안내 스타일 |

## 확인 (실제 Chrome · CDP, 임시 회원/관리자 세션)

브라우저 테스트 통과 — 열린 이벤트 없음 안내/버튼 비활성 · 티어표 공개 탭 회원/관리자 모두 "준비 중"(관리 폼 없음, 관리자만 링크) ·
관리자 페이지 섹션 · 상금 999P 오류 · 작성 중 저장 → 회원에게는 아직 안 열림 · **열기(확인창)** → 회원 화면에 제목·상금 표시 + 게임 시작 → 카드 16장 ·
순위표 · **닫기** → 회원 시작 버튼 비활성 + 최종 순위 · **정산** → 1위 지갑 +1500P·알림 생성 · 티어표 공개 저장/열기/닫기/발표(마감+30분 자동 계산, 발표 후 입력 잠금) ·
다크/모바일(390px) 넘침 없음. 기존 이벤트 페이지 테스트 회귀 통과.

한계: 관리자 목록은 최근 10건. 티어표 공개의 당첨자 선정 UI 는 정식 공개 때 붙인다(지금은 발표 + 참가자 알림만).
