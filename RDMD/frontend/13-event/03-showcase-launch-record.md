# 커밋 요약 — 제작한 티어표 공개 정식 오픈(회원 화면) + 관리자 접수 시작 예약·우승작 직접 선정

백엔드 기록: [`../../backend/09-event/03-showcase-launch-record.md`](../../backend/09-event/03-showcase-launch-record.md)

## 요청

> 접수 상태가 되면 티어표 공개 페이지에서 직접 이벤트용 티어표를 제작해서 올리거나 이미 올린 게시글로 참가.
> 우승자는 관리자가 직접 뽑거나 투표 자동 집계로 포인트 지급.
> 관리자 페이지: 접수 시작 예약(날짜를 직접 골라 그날 열기), 참여 유저 중 직접 우승자 선정 또는 결과 공개일에 투표 수 자동 계산 발표.

## 1. 이벤트 페이지 "티어표 공개" 탭 (회원용, `EventShowcasePanel.jsx`)

이전의 "준비 중" 안내를 진짜 화면으로 바꿨다. 상태별로 다음이 보인다.

| 상태 | 화면 |
|------|------|
| 없음 | "지금 열려 있는 이벤트가 없어요" (최근 발표 회차가 있으면 그 결과를 계속 보여줌) |
| **접수 예정** | 접수 시작·마감·발표 시각, 상금, 우승 방식, **"접수 시작까지 00:02:42" 카운트다운**. 참가 영역은 아직 없음 |
| **접수 중** | 회차 요약 + **참가하기 두 갈래**, 참가작 갤러리(투표) |
| **투표 중 · 접수 마감** | 새 출품은 막히고 **투표는 발표일까지** 계속, "결과 발표까지" 카운트다운 |
| **결과 발표** | 🏆 우승 카드(우승자·작품·표·상금, 우승작 보기) + **표 수가 공개된 최종 순위** |

### 참가하기(접수 중)

1. **✏️ 새 티어표를 만들어서 참가** → `/custom-maker?event=<회차id>` 로 이동. 메이커 위에 "🏆 「제목」 이벤트에 낼 티어표를 만드는 중이에요.
   완성한 뒤 업로드하면 자동으로 참가됩니다" 배너가 뜨고, 업로드 창에 **"이 티어표로 이벤트에 참가하기"(기본 체크)** 가 생긴다.
   업로드하면 게시판에 올라가는 동시에 출품되고 이벤트 페이지로 돌아온다. 접수가 끝났거나 이미 참가했으면 배너가 회색 안내로 바뀌고 자동 출품은 하지 않는다.
   (게시글 업로드는 성공했는데 출품만 실패하면 이유를 알려 주고 게시글은 그대로 남긴다.)
2. **📋 이미 올린 게시글로 참가** → 내 **공개** 글 목록(썸네일 + 제목)에서 고르고 [이 글로 참가하기]. 글을 고르기 전에는 버튼이 비활성.

참가하면 "내 참가작" 줄(+ 접수 중에는 [참가 취소])이 생기고 참가하기 영역은 사라진다.

### 투표

- 카드마다 [👍 투표]. **표는 하나뿐**이라 다른 작품을 누르면 표가 옮겨 가고(이전 카드는 다시 "투표"), 같은 작품을 다시 누르면 취소된다.
  "내가 투표" 태그와 강조 테두리로 내 표가 어디 있는지 보인다. **내 작품 카드에는 투표 버튼이 없다.**
- **투표 중에는 표 수를 보여주지 않는다**(서버가 아예 내려주지 않음). 안내 문구로 미리 알려 준다.
- 비로그인은 로그인 안내, 관리자 계정은 "참가·투표할 수 없어요 — 관리는 관리자 페이지에서" 안내.
- 다음 시각(시작/마감/발표)을 넘기면 화면이 서버에서 새 상태를 다시 받아 자동으로 바뀐다.

## 2. 관리자 페이지 "🖼️ 제작한 티어표 공개" (`AdminEventManager.jsx` → `ShowcaseManager`)

- 폼: 제목 · 설명 · **📅 접수 시작(예약)** · 접수 마감 · 결과 공개(= 투표 종료, 비우면 마감+30분) · 우승 상금 · **우승자 결정 방식**(투표 1위 자동 선정 / 관리자가 직접 선정).
- 버튼: **작성 중으로 저장** / **📅 접수 시작 예약하기**(날짜를 골라 누르면 그 시각에 자동으로 열림) / **지금 접수 열기**. 예약·열기가 거절되면(마감 시각 없음 등)
  입력한 내용을 잃지 않게 저장된 회차로 폼을 되돌려 놓는다. 진행 중인 회차가 있으면 예약·열기 버튼은 비활성.
- 회차 표: 제목(+방식·상금) · 상태 배지(접수 예정(예약됨)/접수 중/투표 중/발표 완료, 공개일이 지났는데 아직 선정하지 않은 직접 선정 회차는 빨간 **"선정 대기"**) ·
  시작/마감/공개 시각 · 참가·투표 수 · 우승자. 상태에 맞는 버튼만 보인다.

| 상태 | 버튼 |
|------|------|
| 작성 중 | 수정 · 예약/열기 · 삭제 |
| 접수 예정 | 수정 · **예약 취소** · 삭제 |
| 접수 중 | 수정 · 참가작 · **접수 닫기** · **발표** |
| 투표 중(마감) | 수정 · 참가작 · **발표** |
| 발표 완료 | 참가작 |

- **참가작 · 득표 표**(선택한 회차): 순위(표 많은 순) · 작품(새 탭으로 게시글 열기) · 작성자 · 표 수 · 제출 시각 + **[우승작으로 선정] / [선정 해제]**.
  직접 선정 방식이면 "선정한 뒤 발표해 주세요(선정 전에는 공개일이 지나도 발표되지 않고 기다립니다)" 경고, 자동 집계 방식이면
  "표가 가장 많은 작품이 우승 — 선정해 두면 그 작품이 우선" 안내.
- [발표]는 확인창("우승자에게 상금이 지급되고 알림이 나갑니다. 되돌릴 수 없습니다") 후 결과를 화면에 남긴다("우승 OOO, 상금 800P 지급 · 알림 발송 완료").

빠른 이동 바의 "🖼️ 티어표 공개" 태그와 이벤트 페이지의 관리자 안내 링크는 `/admin#admin-showcase` 로 도착한다.

## 확인 (실제 Chrome · CDP, 임시 회원 3명 + 관리자 세션)

브라우저 테스트 49건 통과 — 관리자 폼(예약 입력 포함) → **📅 예약** → 표에 "접수 예정(예약됨)"·[예약 취소]·열기 버튼 비활성 → 회원 화면 "접수 예정 + 카운트다운 + 참가 영역 없음" →
예약 시각이 지나면 자동으로 "접수 중" → **내 글로 참가**(공개 글만 목록, 비공개 글 제외) → **메이커에서 새로 제작해 업로드하면 자동 참가**(배너·체크박스·게시글 생성·출품·이벤트 페이지 복귀) →
투표(표 이동, 표 수 숨김, 내 작품 버튼 없음) → 관리자 참가작·득표 표 → **표는 B 가 많지만 A 를 직접 선정 → 발표**(A 우승·상금 800P·알림 3건) → 회원 화면 "결과 발표"·우승 카드·표 수 공개 순위 →
직접 선정 방식 "선정 대기" 배지·경고 → 다크·모바일(390px 넘침 없음). 기존 이벤트 페이지/관리자 이벤트/메모리 기록 테스트 회귀 통과.
