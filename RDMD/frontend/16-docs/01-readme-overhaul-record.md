## 판단

### 운영 DB 와 실제 회원 정보를 쓰지 않았다

- `server.js` 는 `backend/.env` 를 `override: true` 로 읽는다. `MONGO_URI` 를 셸에서 넘겨도 **운영 Atlas 로 붙는다.** 그대로 띄웠다면 데모 계정이 운영 DB 에 들어가고 실제 닉네임이 공개 이미지에 찍혔을 것이다.
- 그래서 `guard-env.js` 를 `node -r` 로 먼저 실행해 `.env` 읽기를 막고, 로컬 임시 Mongo(Docker `127.0.0.1:27099`)가 아니면 연결을 거부하게 했다. 메일과 유튜브 동기화도 끈다.
- 데이터는 `seed-demo.js` 의 가상 닉네임과 글이다.

### 저장소가 공개 상태라는 것을 전제로 만들었다

- 2026-11-05 인증 없이 GitHub API 를 불러 공개 저장소임을 확인했다. 그래서 이미지에 실제 회원 정보를 넣지 않고, 루트 README 에서 서버 IP 를 뺐다.
- `CONTRIBUTING.md` · `SECURITY.md` 의 "비공개" 문구는 사실과 달라 고쳤다. 실제로 clone 을 막으려면 창시자가 저장소를 Private 으로 바꿔야 한다.

### 그림은 PNG, 로직은 Mermaid

- 프레임워크 소개처럼 보여 주는 그림은 PNG 로 만들었다. 로고를 쓸 수 있고 GitHub 테마와 상관없이 같게 보인다.
- 로직 구조는 Mermaid 로 썼다. 코드와 함께 diff 로 고칠 수 있어 낡기 어렵다.
- 다이어그램 안의 숫자와 노드는 코드에서 확인했다(페이지 25 · 라우터 11 · 모델 22 · 캐릭터 338 · 지식 14 · 가이드 5, `graph.py` 노드와 분기, `deploy.sh` 순서).

창시자 지시(2026-09-19)로 수정 금지인 폴더라 10개를 제외했다.

## 확인

- Mermaid 42개를 실제 mermaid 11 로 렌더링 — 처음 13개 실패(엣지 라벨의 `.Agents` 점, f-string 이 삼킨 중괄호)를 고친 뒤 전부 통과.
- 변경된 md 39개의 상대 이미지·링크 경로 전부 존재.
- GIF 마지막 프레임과 정지 화면을 눈으로 확인. AI 장면은 실제 모델(`gemma4:12b`)의 답이고 내용이 맞다.
- 커밋 전 시크릿 패턴 검사. `guard-env.js` 의 관리자·키 값은 임시 DB 전용이다.
- 임시 컨테이너와 서버를 종료했다.

## 찾았지만 고치지 않은 것

- **모바일 메이커 가로 넘침**: 390px 화면에서 `/custom-maker` 의 레이아웃 폭이 404px 로 늘어나 보드 오른쪽이 잘린다(`innerWidth` 404, `#tier-capture-area` 오른쪽 403). 그래서 README 에는 이 화면을 넣지 않았다. 코드 수정이라 이번 범위에서 뺐다.

## 한계
