# 커밋 요약 — 관리자 페이지 버튼 간격 확대

## 요청

> 관리자 페이지 내에서 간격이 너무 붙어있는 버튼을 확인하고, 충분한 거리를 낼 수 있도록 작업.

## 실측

화면의 보이는 버튼 121개를 모두 잡아 **같은 줄에서 나란히 있는 쌍의 가로 간격**과 **같은 열에서 겹쳐 쌓인 쌍의 세로 간격**을 쟀다
(임시 회차를 심어 이벤트 관리 표의 모든 상태 버튼이 나오게 했다). 가로 8px 미만 / 세로 6px 미만이면 "좁음"으로 봤다.

| 위치 | 이전 | 원인 |
|------|------|------|
| 공지 목록 표 (수정 · 고정/고정 해제 · 삭제) | 4px, **"고정 해제 ↔ 삭제"는 0px** | 수정 버튼에만 `margin-right: 4px`, 나머지는 여백 없음 |
| 문의 표 (상세 · 삭제) | 4px | `.action-btn + .danger-btn { margin-left: 4px }` |
| 차단/회원 표 (차단 · 삭제) | 4px | 〃 |
| 이벤트 관리 표 (수정 · 열기/닫기 · 정산 · 삭제) | 4px | `.eadm-actions .eadm-btn + .eadm-btn { margin-left: 4px }` |
| 공지 에디터 서식 툴바 (제목 · 소제목 · B · I …) | 4px | `.notice-editor-toolbar { gap: 4px }` |

합계 좁은 쌍 **50건**(1200px 기준). 버튼마다 따로 준 margin 이라 간격이 들쭉날쭉했고 한 곳은 아예 붙어 있었다.

## 조치

- **표 안 조작 버튼 공통 규칙**(`admin-manage.css` 끝): 칸의 직접 자식 버튼에 `margin: 3px 4px` →
  **버튼 사이 8px**, 칸이 좁아 **줄이 바뀔 때는 줄 사이 6px**. 칸의 양 끝 버튼은 바깥 여백을 0 으로 해 글자 정렬이 안 틀어지게 했다.
  버튼마다 흩어져 있던 개별 margin 대신 한 규칙이 맡는다.
- 이벤트 관리 표의 개별 4px 규칙(`admin-event.css`)은 제거하고 공통 규칙에 맡겼다.
- 공지 에디터 툴바 `gap` 4px → **8px**.
- 버튼 크기·색·글자는 그대로다(간격만 조정).

## 확인

같은 실측을 폭 1200 / 900 / 390px 에서 다시 돌려 **좁은 쌍 0건**(이전 50건). 공지·이벤트 관리·차단 표를 캡처로 눈으로 확인했다.
측정용 임시 회차는 모두 삭제했다.
