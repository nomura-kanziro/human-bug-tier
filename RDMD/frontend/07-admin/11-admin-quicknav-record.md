# 커밋 요약 — 관리자 전용 "빠른 이동" 태그 바 (누르면 해당 기능으로 스크롤)

## 요청

> 관리자 전용 퀵버튼 페이지네이션을 만들어보자. 관련 해당되는 태그 버튼을 누른다면 그 관련 기능에 스크롤해서 내려가는 기능을 구현해줘.

## 왜 필요한가

관리자 대시보드는 댓글 · 커스텀 메이커 신고 · 공지 · 이벤트(메모리 기록 / 티어표 공개) · 차단이 **한 화면에 길게 이어져** 있어
아래쪽 기능(차단, 이벤트 관리)까지 가려면 표 여러 개를 지나 한참 내려가야 했다.

## 구성 (`AdminQuickNav.jsx`, 대시보드 맨 위)

```
빠른 이동 [💬 댓글 2] [🎨 커스텀 메이커 신고 10] [📢 공지 47] [🃏 메모리 기록 이벤트] [🖼️ 티어표 공개] [🚫 차단]        ↑ 맨 위
```

| 태그 | 이동하는 섹션 (id) | 배지 |
|------|--------------------|------|
| 댓글 | `admin-inquiries` (전체 댓글 관리) | 댓글 수 |
| 커스텀 메이커 신고 | `admin-tier` | 신고된 게시글+댓글 수 (**빨간 배지** — 처리할 것) |
| 공지 | `admin-notices` | 공지 수 |
| 메모리 기록 이벤트 | `admin-memory-events` | — |
| 티어표 공개 | `admin-showcase` | — |
| 차단 | `admin-blocks` | 현재 차단 중인 수 |

- 태그 순서는 페이지 위→아래 순서와 같고, 배지는 0이면 숨긴다.
- **헤더 바로 아래에 고정(sticky)** 되어 스크롤해도 계속 보인다.

## 동작

- **부드러운 스크롤 + 가림 방지**: 헤더 + 이 바의 높이를 실측해, 섹션이 그 아래 16px 띄운 자리에 멈춘다(헤더/바에 제목이 가려지지 않음).
- **스크롤 스파이**: 지금 보고 있는 섹션의 태그가 강조된다. 맨 아래까지 내리면 마지막 태그가 켜지고, 태그를 눌러 이동하는 동안에는
  스파이를 잠가 지나치는 섹션의 태그가 차례로 깜빡이지 않게 했다.
- **주소 해시 연동**: 이동하면 `/admin#admin-notices` 처럼 주소가 바뀐다(`replaceState` — 히스토리를 쌓지 않아 뒤로가기가 길어지지 않음).
  해시가 붙은 주소로 열면 **데이터 로딩이 끝난 뒤** 그 섹션으로 이동한다(표가 그려지기 전에 이동하면 위치가 어긋나서,
  기존 `AdminEventManager` 의 "마운트 즉시 스크롤"을 없애고 대시보드가 한 번만 처리하도록 옮겼다).
  이벤트 페이지의 "관리자 페이지 → 이벤트 관리" 링크(`/admin#admin-events`)도 이 경로로 정확히 도착한다. 없는 해시는 무시.
- **접근성**: 태그는 실제 링크(`<a href>`)라 키보드(Tab/Enter)로 동작하고, 현재 위치에 `aria-current`, 이동한 섹션으로 포커스를 옮긴다.
  OS의 "모션 줄이기" 설정이면 애니메이션 없이 바로 이동한다.
- **모바일**: 태그 줄이 줄바꿈 대신 **가로 스크롤**되고(스크롤바 숨김), 켜진 태그가 항상 보이도록 줄 안에서 굴러간다. "빠른 이동" 글자는 숨긴다.
- 색은 테마 토큰이라 라이트/다크가 함께 따라온다. 전역 규칙 `[data-theme="dark"] a { color: 링크 파랑 }` 이 명시도가 더 높아
  다크에서 태그 글자가 파랗게 나오던 것을 잡아 `.admin-quicknav` 아래로 좁힌 선택자로 고쳤다.

## 주요 파일

| 파일 | 내용 |
|------|------|
| `root-cloudflare/src/components/AdminQuickNav.jsx` | 신규 — 태그 바, `scrollToAnchor()`(이동·해시·포커스), 스크롤 스파이 |
| `root-cloudflare/src/styles/admin-quicknav.css` | 신규 — sticky 바·태그·배지·모바일 |
| `root-cloudflare/src/pages/AdminDashboard.jsx` | 바 연결, 섹션에 id/`data-admin-anchor`, 로딩 후 해시 이동 |
| `root-cloudflare/src/components/AdminEventManager.jsx` | 두 블록에 앵커 id, 자체 해시 스크롤 제거 |

## 확인 (실제 Chrome · CDP, 관리자 세션)

브라우저 테스트 통과 — 태그 6개·순서·목적지 존재 · 배지 숫자 · **스크롤해도 헤더 바로 아래 고정** · 6개 태그 각각 클릭 시 섹션이 바 아래 16px 자리에 정확히 멈춤(섹션 top 135px / 바 bottom 120px)
+ 그 태그 활성 + 해시 갱신 · 히스토리 미증가(4→4) · 손으로 스크롤할 때 스파이 6구간 + 맨 아래=마지막 태그 · `↑ 맨 위`(스크롤 0·해시 제거) ·
`/admin#admin-notices`, `/admin#admin-events` 로 열기 · 없는 해시 · 키보드 Enter + 포커스 이동 + `aria-current` ·
헤더 드롭다운이 바에 가려지지 않음 · 모션 줄이기 즉시 이동 · 다크 색 · 모바일 390px(바가 화면 안, 태그 줄 가로 스크롤, 활성 태그 보임).
회귀: 이벤트 관리 브라우저 테스트 통과.

## 알려진 것(이번 변경과 무관)

모바일(390px)에서 관리자 표(댓글·신고 표)가 화면보다 넓어 **페이지가 가로로 넘친다**(변경 전에도 714px 로 동일 확인). 바 자체는 화면 안에 들어오지만,
관리자 표의 모바일 대응은 별도 개선 과제다.
