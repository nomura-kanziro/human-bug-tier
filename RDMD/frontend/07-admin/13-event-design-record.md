# 커밋 요약 — 관리자 "이벤트 디자인 적용" (할로윈 · 크리스마스 사이트 배경)

## 요청

> 사이트 배경을 휴먼버그대학교 다운 컨셉으로. 바로 적용하지 말고 관리자 페이지 "이벤트 디자인 적용"에서
> 할로윈 디자인 on/off · 크리스마스 디자인 on/off — 하나를 켜면 다른 것은 꺼진다. 크리스마스 배경까지 미리 만들어도 좋다.

## 관련 커밋

- `93170c6` (2026-10-17) feat(event-design): 관리자 "이벤트 디자인 적용" — 할로윈·크리스마스 사이트 배경 on/off(한 번에 하나만)

## 동작

- 관리자 페이지 **🎨 이벤트 디자인 적용**(빠른 이동 "이벤트 디자인", 이벤트 관리와 행운 뽑기 관리 사이)에 카드 2개 — 할로윈 / 크리스마스, 각각 ON/OFF 스위치.
- 서버는 값 하나만 저장(`SiteSetting` 의 `seasonalTheme` = `none` | `halloween` | `christmas`)하므로 **동시에 두 개가 켜질 수 없다**.
  할로윈 ON 상태에서 크리스마스를 켜면 할로윈은 자동 OFF, 켜진 것을 다시 누르면 기본 배경.
- 바꾸기 전에 확인창(다른 디자인이 켜져 있으면 "지금 켜져 있는 … 디자인은 꺼집니다" 안내). 바꾸면 관리자 화면에는 즉시 적용.
- 방문자: 페이지를 열 때 `GET /api/site/settings` 로 받아 적용 + 30분마다·탭으로 돌아올 때 재확인. 마지막 값을 `localStorage.hbtSeason` 에 기억해 `index.html` 이 React 보다 먼저 붙여 깜빡임을 줄인다.

## 디자인 — 휴버대 모티프 (2026-10-18 고도화)

로고의 **붉은 눈**, **H** 문장, 로고 옆 **세 자루 창**에 **학교 건물**을 더해 계절 풍경에 녹였다.

**공통 구조(깊이감)** — 층 순서 뒤→앞: 하늘(별·오로라) → 달/초승달·구름 → 먼 언덕 → 고딕 학교 건물 → 가까운 언덕·나무 → 울타리 → 앞 소품 → 안개·불씨/눈 → 비네트.
먼 층일수록 하늘색에 가깝게 흐리고 가까운 층일수록 짙게(`--sb-far` < `--sb-campus` < `--sb-mid` < `--sb-near`) 칠해 대기 원근을 낸다.

| 요소 | 내용 |
|---|---|
| **휴버대 눈**(`HbuEye`) | 흰자(아몬드형) 위에서 **홍채·홍채 고리·동공·하이라이트가 한 묶음(`.sb-eye-look`)** 으로 같이 움직인다. 묶음은 흰자 모양으로 잘려(clipPath) 눈 밖으로 나가지 않고, 멈춰 보다 휙 돌아보는 박자로 움직이며 가끔 깜빡인다. (처음 버전은 홍채에만 이동 애니메이션을 걸어 동공·하이라이트가 멈춰 있었다 — 10-18 수정) |
| **고딕 학교 건물**(`Campus`) | 탑 5개·뾰족지붕·불 켜진 창문 21개(박자를 달리해 깜빡임)·대문. **가운데 탑의 장미창이 휴버대 눈**. 크리스마스에는 지붕 눈·처마 전구가 추가 |
| 울타리 + **세 자루 창** | 창끝 울타리, 일정 간격마다 창 세 자루 기둥(가운데가 더 길게) |
| 나무 | 할로윈: 시드 기반 재귀 생성 **잎 없는 나무**(가지 깊이별 굵기). 크리스마스: 시드 생성 **소나무** 두 겹(먼 것·가까운 것, 눈 덮인 윗면) |

| 할로윈 | 크리스마스 |
|---|---|
| 후광·얇은 고리·분화구·명암이 있는 보름달(가운데 눈), 천천히 지나가는 구름, 박쥐, 눈 모양으로 파낸 호박(그라데이션, 다크에선 불빛 깜빡임), H 묘비, 어둠 속 붉은 눈(오른쪽 나무 가지 사이), 흐르는 안개 두 겹, 떠오르는 불씨 두 겹, 별(다크), 지평선 노을 | 오로라 두 줄, 초승달, 헤더 아래 전구 가랜드, 눈 덮인 건물, 눈알 오너먼트 트리·선물·가로등(불빛 숨쉬기), 눈 세 겹(멀·중·가까움), 별(다크) |

- 본문이 읽히도록 **라이트는 밝은 계절 배경**(할로윈 살구빛→연보라, 크리스마스 눈빛 하늘색), **다크는 어두운 계절 배경**(할로윈 보랏빛 밤, 크리스마스 남색 밤)으로 팔레트를 따로 두었다. 카드 배경은 그대로.
- 장식 층은 `position:fixed; z-index:-1; pointer-events:none` — 본문 클릭·스크롤에 영향 없음.
- **밝은 테마에서는 달 대신 태양**(2026-10-18): 할로윈 보름달 자리에 16방향 광선(120초에 한 바퀴 회전)·노란 원반·따뜻한 후광의 태양이 나오고 가운데에 같은 휴버대 눈이 있다. 크리스마스 초승달은 작은 태양(12방향 광선)으로 바뀐다. 달과 태양을 같은 자리에 둘 다 그려 두고 CSS(`html:not([data-theme="dark"])`)로만 전환해, 헤더 테마 스위치를 누르면 바로 바뀐다(`makeRays()` 로 광선 생성).
- 불씨·눈 반복은 타일 크기의 정수배만 이동시켜 **이음매 없이** 반복한다(처음 버전은 눈이 한 바퀴 돌 때 튀었다).
- 768px 이하: 달·구름·붉은 눈·일부 박쥐·가까운 눈을 줄이고(달은 모서리로 작게), 건물이 화면 가운데에 오도록 풍경이 좌우로 잘리고, 가랜드는 화면보다 넓게 그린다.
- `prefers-reduced-motion: reduce` 이면 모든 애니메이션을 끈다.

## 확인

- 컨트롤러를 가짜 저장소로: 처음 none → 할로윈 → 크리스마스(할로윈 자동 해제) → none, 허용 외 값 400.
- 가짜 서버(빌드된 dist + 메모리 설정 API, 운영 DB 미접속) + Chrome DevTools Protocol:
  홈을 PC(1300)·모바일(390) × 라이트·다크 × 두 계절로 캡처, 관리자 섹션에서 할로윈 ON → 크리스마스 클릭(확인창 문구·할로윈 OFF·배경 교체) → 크리스마스 클릭(기본 배경) 확인.
- 첫 캡처에서 박쥐가 점처럼 작고, 크리스마스 가랜드가 홈 제목 뒤에 겹치고, 모바일에서 달이 소개 글 뒤에 깔리는 문제를 찾아 고친 뒤 다시 확인.
- 10-18 고도화 확인: 눈 묶음의 자식 4개(홍채·고리·동공·하이라이트)가 하나의 `g` 에 들어 있고 개별 transform 이 없음을 브라우저에서 읽고, 그 묶음의 transform 이 시간에 따라 `(0,0) → (-8,-1) → (7,1.4) → (2,-2)` 로 바뀌는 것을 측정. 본문·헤더를 숨기고 배경만 PC·모바일 × 라이트·다크 × 두 계절 캡처해 검토 — 묘비가 언덕과 같은 색이라 H 글자만 떠 보이던 것, 붉은 눈이 허공에 뜬 것, 선물이 눈 언덕에 묻힌 것, 다크에서 박쥐가 하늘색과 같아 안 보이던 것을 찾아 고침.
- 10-18 태양 확인: 테마를 밝음→어두움→밝음으로 바꿔 두 계절 모두 달/태양의 `display` 가 서로 반대로 바뀌는 것을 읽고, 태양 눈 묶음(자식 4개)이 달과 같이 한 묶음으로 움직이는 것·광선 회전을 측정, PC·모바일(할로윈 태양, 크리스마스 작은 태양) 캡처 확인.
- **운영 배포·실제 서버 저장은 아직 하지 않았다**(커밋만).
