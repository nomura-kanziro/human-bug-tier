# 유튜브 새 소식 이미지·링크 표시

## 개요
유튜브에서 가져온 새 소식 본문의 `![이미지](url)` 과 원문 링크가 상세 페이지에 렌더링되게 했다. 일본어 글은 한국어로 번역해 보여 주고, 상세에서 원문을 토글할 수 있다. 관리자 페이지에서 즉시 가져오기 버튼을 둔다.

## 변경된 파일
- `notice/notice.js` — 이미지 마크다운, YouTube 뱃지
- `notice/notice.css` — 본문 이미지·갤러리
- `admin/comments/comment-management.html` / `.js` / `.css` — 동기화 버튼·상태

## 테스트
1. `:5000/notice/news.html` 에서 YouTube 뱃지 확인
2. 상세에서 이미지와 `유튜브 커뮤니티에서 보기` 링크
3. 관리자 페이지 **유튜브 게시판 가져오기**
4. 모바일 너비에서 이미지가 넘치지 않는지 확인
