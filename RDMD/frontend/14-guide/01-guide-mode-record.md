# 가이드 전용 페이지 + "가이드 모드" (1.1.0 준비)

## 요청

> 1.1.0 버전을 만들기 위해 가이드 전용 페이지를 만든다. 설명식이 아니라 게임처럼, 가이드 모드를 켜면 가이드를 해 주는 모드로 바뀌고
> 왼쪽 아래에 작은 원형 ✕ 버튼이 생겨 누르면 가이드 모드가 끝난다.

## 동작

- **`/guide`** (푸터 "이용 안내 → 가이드"): 시작 화면. "▶ 가이드 모드 켜기" + **스테이지 카드 5개**(클리어 표시, "시작/다시 하기"), 클리어 n/5, 클리어 기록 지우기.
  - 켜기 버튼은 아직 안 깬 첫 스테이지부터 이어서 시작한다(다 깨면 "처음부터 다시 하기").
- **가이드 모드가 켜지면**: 화면 전체가 어두워지고 짚을 곳만 밝게 뚫린 채 노란 테두리가 숨 쉬듯 깜빡인다. 옆에 **한 줄짜리 말풍선**(스테이지 이름 · n/총 · 진행 막대 · 이전/다음). 강조 틀은 다음 대상으로 부드럽게 미끄러진다.
- **왼쪽 아래 동그란 ✕ 버튼**(PC 46px / 모바일 44px)을 누르면 가이드 모드 종료. Esc 도 종료, ←/→ 로 단계 이동.
- 켜진 동안은 **뒤 화면 클릭을 막아** 실수로 눌러 흐름이 끊기지 않는다(스크롤은 된다). 단계가 다른 화면이면 알아서 이동한다.
- 마지막 단계의 "클리어! 🎉" → "STAGE CLEAR" 알림(2.6초) 후 `/guide` 로 돌아오고 클리어가 저장된다.
- 대상 요소를 3초 안에 못 찾으면(로그인 상태에 따라 없는 버튼 등) 강조 없이 화면 아래 가운데에 말풍선만 띄운다.

| 스테이지 | 단계 | 내용 |
|---|---|---|
| 1 첫 걸음 | 6 | 로고 · 메뉴 · 테마 · 알림/로그인 · 공지 · 티어표 |
| 2 티어표 보기 | 3 | 티어 전환 · 요약 · 순위 |
| 3 나만의 티어표 | 6 | 캐릭터 풀 · 검색 · 배치 · 꾸미기 · 다운로드 · 업로드 |
| 4 게시판 | 3 | 검색 · 목록 · 글쓰기 |
| 5 이벤트·행운 뽑기 | 3 | 이벤트 탭 · 뽑기 탭 · 포인트 |

## 구조

| 파일 | 역할 |
|---|---|
| `src/lib/guideCourses.js` | 스테이지·단계 정의(`route` · `target` 선택자 목록(보이는 첫 번째 사용 — PC/모바일 겸용) · `text`). 단계를 늘리려면 여기만 고친다 |
| `src/lib/guide.js` | 상태 저장소(`useSyncExternalStore`). 진행 중인 스테이지·단계는 `sessionStorage.hbtGuideSession`(새로고침해도 이어짐), 클리어는 `localStorage.hbtGuideCleared`. 서버 저장·백엔드 변경 없음 |
| `src/components/GuideMode.jsx` | 오버레이. `main.jsx` 에서 앱 최상위에 렌더 → 어느 화면에서나 동작. 대상 찾기(120ms 폴링, 최대 3초) → 스크롤 → 매 프레임 위치 추적, 말풍선 위치(아래 → 위 → 화면 아래 가운데) |
| `src/pages/Guide.jsx` + `App.jsx` 라우트 + `Footer.jsx` 링크 | 시작 화면 |
| `src/styles/guide.css` | 시작 화면 + 오버레이. z-index 11000(헤더 패널 10000 위). `prefers-reduced-motion` 이면 애니메이션 끔 |

## 확인

- 빌드 통과. 가짜 서버 + Chrome DevTools Protocol 로 PC(1300)·모바일(390): 스테이지 1~4 의 모든 단계가 강조 대상을 찾아 정상 표시되고 마지막에 `/guide` 로 돌아오며 클리어가 저장됨. 스테이지 5 의 행운 뽑기 단계 표시 확인.
- 모바일에서 메뉴 단계가 햄버거 버튼(`#menuBtn`)을 강조(PC 는 `.desktop-nav`).
- ✕ 버튼 위치(왼쪽 18px·아래 18px / 모바일 12px) 와 클릭 시 오버레이·세션 제거 확인.
- **가짜 서버에는 이벤트 API 가 없어 `/event` 화면이 스스로 오류로 멈춘다**(가이드와 무관, 운영 서버는 정상 응답) — 스테이지 5 의 이벤트 탭 단계는 운영에서 확인이 필요하다.
- 운영 배포·버전(1.1.0) 변경은 아직 하지 않았다.

## 수동 테스트

1. 푸터 → 가이드 → "가이드 모드 켜기" → 말풍선·강조·다음/이전
2. 왼쪽 아래 ✕ → 즉시 종료(세션 제거), Esc 도 동일
3. 한 스테이지 끝까지 → STAGE CLEAR → `/guide` 카드에 CLEAR ✓
4. 중간에 새로고침 → 같은 단계에서 이어지는지
5. 모바일 폭에서 메뉴 단계(햄버거 강조)·말풍선이 화면 밖으로 안 나가는지
6. 로그인/비로그인 양쪽에서 알림·글쓰기 단계가 어색하지 않은지
