# 커밋 요약 — 커스텀 메이커: 바닐라 기능 이식(드래그 자동 스크롤 · 풀 ▲▼) + 다중 선택 · 풀 검색 · 이벤트 참여

## 요청

> render.com(바닐라)에 있는 커스텀 메이커 기능을 Cloudflare(React)에도 넣어줘. 없는 것:
> ① 캐릭터를 드래그해 화면 위아래 끝에 대면 자동 스크롤 ② 전체 캐릭터 풀의 ▲▼ 버튼(▲ 티어표로, ▼ 맨 아래로) ③ 이벤트 참여하기(티어표 공개로 업로드)
> 새로 추가했으면 하는 것:
> ④ Ctrl+클릭 다중 선택, Shift+클릭으로 왼쪽 위~오른쪽 아래 사이 전부 선택 ⑤ 풀 카드가 상자 천장에 붙어 있으니 위쪽 여백을 줘서 가운데로
> ⑥ 풀 위쪽 가운데에 검색창 — 입력 중에는 비슷한 이름 최대 5명, 검색하면 이름이 **100% 일치**하는 카드로 스크롤

`root-render/` 는 베타 종료(수정 금지)라 **읽기만 하고 동작을 확인한 뒤 React 로 옮겨 적었다.**

## 1. 바닐라에서 옮긴 것

| 기능 | 바닐라 | React 이식 |
|------|--------|-----------|
| 드래그 자동 스크롤 | `initAutoScroll()` — `dragover` 에서 화면 위/아래 80px 안이면 16ms 마다 ±15px | `useEffect` 로 `dragover`/`dragend`/`drop` 리스너 등록, 방향이 바뀔 때만 타이머를 새로 건다. 언마운트 시 정리 |
| 풀 ▲▼ 버튼([10번 기록](./10-pool-viewport-arrows-record.md)) | `initPoolMaxWindow()` + `body.pool-arrows-on` | `IntersectionObserver` 로 풀이 보이는 동안만 렌더(React 가 직접 그리므로 body 클래스 대신 `.is-on`). ▲ = 티어표(`#tier-capture-area`)로, ▼ = 풀 끝 + 풀 안쪽 스크롤 맨 아래 |

- CSS(`.pool-viewport-arrows`, `.pool-arrow`)는 예전 동기화로 이미 들어와 있어 **표시 규칙만** 더했다.
- ▲ 는 바닐라의 `top: 12px` 를 그대로 쓰면 React 헤더(메뉴 바가 생겨 더 높다)를 가려서, Header 가 실측해 넣어주는
  `--header-h` 를 써 **헤더 바로 아래**로 내렸다. 같은 이유로 선택 안내 막대(`.mobile-place-hint`)의 `top: 56px` 고정값도 `--header-h` 기준으로 바꿨다.

## 2. 이벤트 참여하기

이전 커밋(`76be645`)에서는 **이벤트 페이지 링크(`?event=`)로 들어왔을 때만** 참가할 수 있었다. 이제 메이커에서 바로 참가할 수 있다.

- 진행 중인(접수 중) 회차가 있으면 링크 없이 들어와도 **업로드 버튼 바로 오른쪽**에 **[🏆 이벤트 참여]** 버튼이 생긴다.
- **로그인 여부와 무관하게 보인다** — 접수 기간(`status: 'open'`)인지만으로 노출을 정하고, 로그인이 필요한지는 눌렀을 때
  업로드 버튼과 똑같은 규칙(`onUploadClick`)으로 안내한다(로그인 안 했으면 "로그인이 필요합니다" → `/login`). 처음엔 로그인한
  사용자에게만 보이는 서버 판정(`viewer.canEnter`)을 그대로 썼다가, 비로그인 방문자에게 아예 버튼이 안 보이는 문제가 있어
  **"접수 기간이면 우선 보여주고, 로그인은 클릭 시 확인한다"** 는 업로드 버튼과 같은 방식으로 고쳤다(후속 요청으로 반영).
- 관리자 계정에는 보이지 않는다(참가할 수 없는 역할이라 억지로 눌러도 서버가 막는다).
- 이미 참가한 회원, 접수 기간이 아닌 회차(작성 중·예약·마감·발표 후)에는 버튼이 뜨지 않는다.
- 업로드 창의 "이 티어표로 이벤트에 참가하기" 체크는 **이벤트 링크로 왔거나 [이벤트 참여]로 열었을 때만 기본 켜짐**이다.
  그냥 [업로드]로 열면 체크박스는 보이되 꺼져 있다 — 이벤트가 열려 있다고 해서 올리는 글이 자동 출품되면 안 되기 때문.
- 안내 배너는 예전처럼 **링크로 들어왔을 때만** 보여 준다(그냥 제작하러 온 사람에게는 버튼만).

## 3. 다중 선택 (신규)

`selectedId`(1명) → `selectedIds`(여러 명)로 바꿨다.

| 조작 | 동작 |
|------|------|
| 그냥 클릭 | 1명 선택(같은 카드를 다시 누르면 해제) — 예전과 동일 |
| **Ctrl(⌘)+클릭** | 하나씩 더하기, 이미 고른 카드면 빼기 |
| **Shift+클릭** | 기준점(마지막으로 그냥/Ctrl 로 누른 카드)부터 지금 누른 카드까지 전부 — 풀에 놓인 순서가 곧 왼쪽 위 → 오른쪽 아래 순서다 |
| 티어 칸 클릭 | 고른 사람 **전부**를 고른 순서대로 배치 |
| 고른 카드 중 하나를 드래그 | 고른 전부가 함께 옮겨간다(카드 위에 떨어뜨리면 그 자리부터 차례로 삽입) |

- 안내 문구가 2명 이상이면 "N명 선택됨 → 티어 칸을 누르면 한 번에 들어갑니다"로 바뀐다.
- 선택 중에는 드롭존 테두리가 강조된다 — CSS(`body.char-selected-mode`)는 있었는데 React 가 그 클래스를 붙이지 않아 죽어 있던 것을 살렸다.

## 4. 풀 여백 · 검색 (신규)

- `.characters-pool` 위쪽 여백 20px → **28px**(모바일 18px). 첫 줄 카드가 상자 천장에 붙어 잘린 것처럼 보이던 문제 해결.
- 풀 상자 **맨 위와 가운데 사이, 가로 중앙**에 검색창(입력 + [검색하기] + 지우기 ✕).
  - 입력 중: 이름이 검색어로 **시작**하는 캐릭터를 먼저, 그다음 포함하는 캐릭터 — **최대 5명** 추천(썸네일·이름·티어). 추천을 누르면 바로 그 카드로 이동.
  - [검색하기]: 이름이 **정확히 같은**(대소문자·공백 무시) 캐릭터 카드로 부드럽게 스크롤하고 2.6초 동안 강조(`.char.is-found`).
    이미 티어에 배치된 캐릭터면 티어표 쪽 카드로 간다. 일치하는 이름이 없으면 "추천에서 골라보세요" 안내.
