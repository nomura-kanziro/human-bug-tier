# 티어표 꾸미기 — 할로윈 배경 이펙트 · 이펙트 색 고르기

## 요청

> 배경 이펙트에다가 할로윈 버전도 만들고, 배경 이펙트 색도 변경할 수 있도록.

(여기서 "배경 이펙트"는 커스텀 티어 제작의 **꾸미기 패널**에 있는 배경 이펙트다. 관리자 "이벤트 디자인 적용"의 사이트 배경과는 별개.)

## 동작

- **할로윈 이펙트**(11번째 이펙트, 빠른 테마에도 "할로윈" 추가): 보랏빛 밤 바탕, 오른쪽 위 주황 보름달 후광, 바닥에서 올라오는 호박빛, 깜빡이는 도깨비불 점, 안쪽 점선 테두리. 사이트 할로윈 배경과 같은 주황 + 보라 팔레트.
- **이펙트 색**(꾸미기 패널의 새 줄): `기본색` 버튼 + 스와치 10개 + 직접 선택. 배경 이펙트가 `없음`이면 비활성(안내 문구 표시).
  - 고른 색은 이펙트의 **빛 색**(후광·글로우·점)만 바꾸고, 바탕 어두운 색과 테두리 색(`borderColor`)은 그대로다. 테두리 색과 이펙트 색은 따로 고른다.
  - 오로라처럼 두세 색을 겹치는 이펙트는 고른 색에서 **색상만 +70° / -35° 돌린 짝색**을 같이 써서 한 색으로도 어울린다.
  - 빠른 테마를 누르면 이펙트 색은 기본색으로 돌아간다. 다른 이펙트를 고르면 고른 색은 유지된다.

## 저장 형식

`{ borderColor, effect, effectColor }` — `effectColor` 는 `#rrggbb` 또는 빈 문자열(= 이펙트별 기본색). 옛 글·옛 저장값은 `effectColor` 가 없어도 빈 값으로 읽혀 **모양이 그대로**다. 잘못된 값은 금색이 아니라 빈 값으로 떨어진다(`sanitizeEffectColor`). 기본값(금색·이펙트 없음·이펙트 색 없음)인 등급은 게시글 저장에서 빠진다. 백엔드 변경 없음(`tierData.style` 자유 Object).

## 구현

| 파일 | 내용 |
|---|---|
| `src/lib/tierStyle.js` | `effectColor` 정규화·저장, `TIER_EFFECT_SWATCHES`, `halloween` 이펙트·프리셋, 색상 돌리기(`hueShiftedRgb`), `tierStyleProps()` 가 색을 골랐을 때만 `--fx-rgb`/`--fx2-rgb`/`--fx3-rgb`/`--fx-line`/`--fx-glow`/`--fx-soft` 를 인라인으로 덮어씀 |
| `src/styles/custom-maker.css` | 이펙트별 기본색을 `--fx-*` 변수로 바꿔 `rgba(var(--fx-rgb), 알파)` 로 사용(기존 이펙트 모양은 유지). `glow`/`neon` 은 `var(--fx-glow, var(--tier-glow))` 식으로 이펙트 색이 있으면 우선. 할로윈 규칙·`decorate-flicker`, reduced-motion 에서 애니메이션 끔 |
| `src/components/DecoratePanel.jsx` | "이펙트 색" 줄, 빠른 테마 누르면 색 초기화 |

html2canvas 로 PNG/PDF 에 찍히도록 `mix-blend`·`backdrop-filter` 없이 그라데이션·box-shadow·의사요소만 쓴다(기존 규칙 유지).

## 확인

- 빌드 통과. 가짜 서버 + Chrome DevTools Protocol 로 `/custom-maker` 에 저장값을 넣어 캡처: 할로윈 기본(주황), 할로윈+파랑(달·바닥빛이 파랑으로, 테두리는 주황 유지), 오로라+분홍. `--fx-rgb` 계산값이 각각 `255, 122, 26` / `77, 141, 255` / `255, 77, 205` 임을 확인.
- 첫 캡처에서 도깨비불 점이 너무 작아 안 보여 점 크기를 키움.
- 운영 배포는 하지 않았다(커밋만).

## 수동 테스트

1. 커스텀 메이커 → 꾸미기 → 빠른 테마 "할로윈" / 배경 이펙트 "할로윈"
2. 이펙트 색 스와치·직접 선택 → 후광·글로우 색이 바뀌고 테두리 색은 그대로인지
3. `기본색`으로 되돌아오는지, 이펙트 `없음`에서는 색 줄이 비활성인지
4. PNG 다운로드에 이펙트·색이 찍히는지, 업로드 후 상세·글 수정에서 같은 색으로 복원되는지
5. 이전에 올린 글(이펙트 색 없음)이 예전 모양 그대로인지
