# 2티어 "무급" 신설 + 6명 이동

## 요청

> 2티어에 "무"라는 등급이 생김. 2티어 무급에서의 인물 목록 > 긴다 에이카쿠, 카니, 타츠미 하루키, 아소 세나, 이부 하야토, 와나카 소이치로. 이 6명을 옮길 것

## 변경 (정본 `root-cloudflare/src/data/tiers.json`)

| 캐릭터 | 이전 | 이후 |
|---|---|---|
| 긴다 에이카쿠 · 타츠미 하루키 · 아소 세나 · 이부 하야토 · 와나카 소이치로 | 3티어 갑급 | **2티어 무급** |
| 카니 | 2티어 정급 | **2티어 무급** |

- 2티어 구성: 갑 7 · 을 3 · 병 9 · 정 8(카니 빠짐) · **무 6**. 3티어 갑급은 23 → 18명.
- 무급은 정급 아래(맨 아래)에 두고, 6명은 요청에 적힌 순서 그대로 넣었다. 갑을병정무의 순서를 따른 해석이다.
- 세부등급 줄은 `tiers.json` 의 `rows` 를 그대로 그리는 구조라 화면 코드(티어표·커스텀 메이커·퀴즈 보기)는 고치지 않았다.

## 이미지는 옮기지 않았다

5명의 사진은 `3 tier/` 폴더에 그대로 두고 `tiers.json` 의 `img` 경로도 바꾸지 않았다. 게시판 글에 캐릭터 이미지 경로가 저장돼 있어(`makerState.js`),
파일을 `2 tier/` 로 옮기면 이 캐릭터를 쓴 옛 글의 사진이 깨진다. 그래서 "이미지 폴더 = 티어 번호" 규칙의 예외가 생겼다(스킬·기능 문서에 적음).
카니는 원래 `2 tier/kani.jpg` 였다.

## 행운 뽑기 풀 (`backend/data/luckPool.js`)

- 5명을 3티어 → 2티어로 옮겼다(카니는 풀에 없음). 안 옮기면 행운 뽑기에서 공식 티어와 다른 티어·포인트가 나온다.
- 그러면 3티어 풀에 루이스 1명만 남아 3티어(출현 6%)가 항상 같은 얼굴이 되므로, 3티어 갑급에서 **야기라 카즈미츠 · 시노미야 타케시 · 이누와시 · 파비앙 주니어** 4명을 채웠다. 요청에 없던 선택이라 바꿔도 된다.
- 풀: 2티어 6 → 11명, 3티어 6 → 5명.

## AI 도우미 지식

- 캐릭터 티어 답변은 `tiers.json` 에서 자동으로 읽으므로 6명은 새 위치로 답한다.
- 사람이 쓴 설명은 고쳤다: `02-tier-guide.md`(2티어 5단계), `09-faq.md`, `10-glossary.md`(무급), `knowledge.py` `GRADE_ORDER_NOTE`.

## 확인

- `tiers.json` 의 모든 `img` 파일이 실제로 있음(누락 0), 행운 뽑기 풀 이미지도 누락 0.
- `tierCatalog.js` 가 2티어 슬롯에 `무급` 을 포함해 읽음(이벤트 퀴즈 보기에 자동 반영).
- `ai-service` 테스트 42개 통과, `npm run build` 성공.
- 화면(`/tier/2`, 커스텀 메이커 2티어 줄)은 브라우저로 직접 보지 못했다.

## 수동 테스트

1. `/tier/2` 에 무급 줄이 정급 아래에 6명으로 나오는지, 이미지가 모두 뜨는지
2. `/tier/3` 갑급에서 5명이 빠졌는지
3. 커스텀 메이커 2티어 줄에 무급 칸이 생기고, 옛 게시글(3티어에 이 캐릭터를 둔 글)의 사진이 그대로 뜨는지
4. 서버를 다시 켠 뒤 행운 뽑기·이벤트 퀴즈(서버는 켜질 때 파일을 읽는다)
