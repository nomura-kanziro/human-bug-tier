# 커밋 요약 — 5티어 하야미 타이키 중복(이미지 없는 상자) 제거

## 요청

> 티어표 페이지 테이블 5티어에 하야미 타이키 이름이 겹치는데, 이미지 없는 캐릭터 상자만 없애줘.

## 원인

`root-cloudflare/src/data/tiers.json` 5티어 병급에 **같은 이름이 두 번** 들어 있었다.

| 항목 | 이미지 파일 | 실제 파일 |
|------|-------------|-----------|
| 하야미 타이키 (사메즈 세이지 뒤) | `5 tier/hayami taiki.jpg` | 있음 |
| 하야미 타이키 (카즈키 시온 뒤) | `5 tier/hayami taiki.webp` | **없음** — 이미지 없는 상자 |

`.jpg` 가 실제 파일이고 `.webp` 는 파일이 없는 잔여 항목이라, 그 항목만 지웠다(이미지가 있는 쪽은 그대로).

## 확인

- 5티어 페이지에서 "하야미 타이키" 가 **1번**만 나온다
- 1~9티어 전 페이지에서 로딩 실패한 캐릭터 이미지 0건(이미지 32/28/61/38/42/36/37/17/50개)
- 데이터 전체를 파일 존재 여부로 대조해 **이미지 파일이 없는 항목이 더 이상 없음**을 확인
- `tiers.json` 은 이벤트 퀴즈 출제에도 쓰이므로(`backend/data/tierCatalog.js`) 퀴즈에서도 없는 이미지가 나올 일이 사라졌다

## 알려진 것(손대지 않음)

7티어에 **카타쿠라**가 이름·이미지(`7 tier/katakura.webp`)까지 동일하게 두 번 들어 있다. 이미지가 있어 "이미지 없는 상자"
는 아니므로 이번 요청 범위에서 제외했다. 지울지는 별도로 정하면 된다.

## 주요 파일

- `root-cloudflare/src/data/tiers.json`
