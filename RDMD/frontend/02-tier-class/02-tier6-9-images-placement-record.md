# 공식 6~9티어 이미지 연결 및 1·2티어 배치

## 개요
6~9티어 페이지는 이름만 있고 이미지 경로가 비어 있었다. 캐릭터 폴더 이미지와 HTML을 맞추고, 일부 인물을 티어·칸 안에서 옮겼다.

## 관련 커밋
- **73dd9bd** — `feat(tier-class): 공식 6~9티어 캐릭터 이미지 추가`
- **13186fd** — `feat(tier-class): 6~9티어 이미지 연결 및 1·2티어 배치 변동`

## 변경된 파일
- `tier-class/tier1.html` ~ `tier2.html`, `tier6.html` ~ `tier9.html`
- `tier-image/1 tier/` ~ `2 tier/`, `6 tier/` ~ `7 tier/` (파일 이동)

## 주요 구현
1. 6~9티어 카드 `img src`를 `tier-image/N tier/{파일명}`에 연결
2. 우사미 쥰페이: 7티어 폴더·페이지 → 6티어
3. 1티어 재배치: 세르지오 1병(세라 왼쪽), 누에 토모야·겐 운란, 시덴·야마모토·미스트, 헤이지(토시야 오른쪽)
4. 미카도 이로치타: 1정 → 2갑 맨앞 (이미지 폴더 이동)
5. 이쥬인 시게오: 2갑 → 2을 맨끝
6. 제이크·사이: 2갑 → 1정, 마치다 앞 (이미지 폴더 이동)

## 변경 전/후
| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 6~9티어 | 빈 `img src` | 캐릭터 이미지 표시 |
| 티어 이동 | HTML만 또는 폴더만 | HTML + `tier-image/N tier` 함께 이동 |

## 테스트
