# 커밋 요약 — 디자인 현대화 2차 (전 페이지 순회: 공통 셸 · 티어표 · 공지 · 문의 · 게시글 · 알림 · 마이페이지 · 메이커 · 관리자)

## 질문과 결론

> 사이트가 디자인 고도화된 게 맞나? 부족하면 모든 부분을 돌아가면서 더 현대화해라.

**부족했다.** 1차(`22ec329`)는 서체·토큰·로그인·게시판·행운 뽑기 첫 탭까지였고, 나머지 화면은 그대로여서 사이트 안에서
"현대적인 화면"과 "옛날 화면"이 섞여 있었다. 전 페이지를 캡처(라이트·다크·모바일)해 화면별로 순회하며 고쳤다.

## 화면별 문제와 조치

| 화면 | 발견한 문제 | 조치 |
|------|-------------|------|
| **공통 헤더** | 흰 단색 바, 메뉴 hover 없음, 로그인 버튼만 원색 파랑 | 반투명 유리 바(블러) · 알약 hover · 드롭다운 카드화 · 로그인 버튼을 강조색으로 |
| **공통 푸터** | 글자 한 줄("site version"+"문의하기"), 짧은 페이지에서 화면 중간에 떠 있음 | 소개 + 바로가기 + 버전 푸터, 본문이 짧아도 화면 바닥에 붙게 |
| **404** | 기본 파란 밑줄 링크 한 줄(+ `<a href="/">` 전체 새로고침) | 큰 404 + 안내 + 버튼 3개(`<Link>`) |
| **빈 상태** | 색 없는 회색 글자 한 줄 | 점선 카드 |

| **공지 페이지** | 제목이 왼쪽 컬럼에만 걸려 보이고 컬럼 위에 굵은 초록/보라 띠 | 컬럼을 카드로, 띠 제거, 홈 미리보기와 같은 토큰 |
| **문의** | 굵은 검정 4px 테두리 + 8px 오프셋 그림자(neo-brutalist), 다크에서 입력창 글자 검정 고정 | 얇은 토큰 테두리 · 부드러운 그림자 · 강조색 버튼 · 테마를 따르는 입력창 |
| **게시글 상세** | 데스크톱 **컨테이너 규칙이 아예 없어** 작성자 줄이 화면 가장자리에 붙고 "댓글 0"이 잘림 | 컨테이너 신설, 헤더/설명/댓글/버튼/신고 모달 토큰화 |
| **알림** | 파랑 탭·라벨, 빈 상태 글자만 | 강조색 탭, 안 읽음에 왼쪽 강조 막대, 점선 빈 상태 카드 |
| **마이페이지** | 파랑 강조(#007bff) | 사이트 강조색 |
| **커스텀 메이커** | 라이트 모드에서 검정+노란 2px 버튼이 가장 무거움, 노란 제목이 흰 배경에서 안 읽힘 | 알약 버튼(hover만 강조색), 드롭다운 카드, 등급 탭, 제목 색 대비 개선 (캡처/내보내기 영역은 손대지 않음) |
| **관리자** | 원색으로 꽉 찬 파랑/보라/초록/빨강 필터 바, 컨테이너 클래스명 불일치(`.admin-container` vs CSS `.admin-main`)로 폭 제한 없음 | 옅은 틴트 바 + `--accent` 로 섹션 색 정체성 유지, 컨테이너 규칙 수정 |

## 기술 메모

- **헤더 블러는 `::before` 에만 건다.** `.side-menu`(모바일 사이드 메뉴, `position: fixed`)가 `<header>` 안에 들어 있는데,
  `backdrop-filter` 는 그 요소를 자손 fixed 의 기준으로 만들어 버려 header 에 직접 걸면 사이드 메뉴가 통째로 깨진다.
  실측: 사이드 메뉴가 `position: fixed`, 뷰포트 우측/상단에 정상 배치.
- **푸터 바닥 고정**: 본문+푸터를 `.app-body`(flex column, `min-height: 100dvh - 헤더`)로 묶고 본문을 `flex: 1`. 헤더는 밖에 둬서 sticky 유지.
  본문 자식들의 `margin: auto` 때문에 폭이 줄어드는 문제를 피하려 flex 를 페이지 요소가 아니라 래퍼(`.app-main`)에만 적용했다.
- 색은 값만 토큰(`var(--bg-elevated)` 등)으로 바꿔 라이트/다크가 자동으로 따라오게 했다. 기존 주석은 지우지 않았다.
- 화면별 다크 덮어쓰기 규칙 중 새 강조색과 충돌하던 것(문의 등록 버튼이 회색으로 남던 것 등)은 함께 고쳤다.
