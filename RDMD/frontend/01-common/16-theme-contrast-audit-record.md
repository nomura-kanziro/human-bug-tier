# 커밋 요약 — 전 페이지 라이트/다크 색 겹침(대비) 전수 점검·수정

## 요청

> 테마 설정에서 색 겹치는 거 — 모든 페이지 둘러봐서 어둡거나 밝을 때 색 겹쳐 보이지 않는 문자나 도형 확인해서 수정해봐.

## 점검 방법

헤드리스 Chrome 으로 **전 페이지 38개 화면 × 라이트/다크** + 열리는 화면 8종(헤더 드롭다운·사이드 메뉴·프로필 메뉴·알림 패널·
메이커 다운로드 메뉴·꾸미기 패널·검색 추천·업로드 모달)을 비회원/회원/관리자 세션으로 열고, 화면에 보이는 모든 글자·버튼·입력칸·아이콘에 대해

- **글자**: 실제 글자색(요소 투명도 반영) vs 실제로 깔린 배경(반투명 레이어·그라디언트 색까지 합성)의 WCAG 대비
- **도형**: 바탕·테두리를 그렸는데 바로 밑 배경과 구분이 안 되는 버튼·입력칸·카드
- **placeholder**, **SVG 아이콘**

을 측정했다. 수정 전 712건(그중 2:1 미만 "거의 안 보임" 279건) → 수정 후 남은 것은 이모지(색 무관)·비활성 버튼(의도적 흐림)·
장식용 점·테두리 없는 툴바 텍스트 버튼처럼 **의도된 것**만 남았다.

## 원인 패턴과 수정

대부분 "다크 안전망 규칙이 너무 세서 원래 색을 덮어쓴" 구체성(specificity) 문제였다.

| 증상 | 원인 | 수정 |
|------|------|------|
| **다크: 공식 티어표 6~9등급 캐릭터 이름이 안 보임**(검정 위 검정) | `theme.css`·`custom-maker.css` 의 `[data-theme="dark"] .char`(메이커 카드용)가 티어표 보드 카드까지 어둡게 칠함 | `tier-board.css` 에 `[data-theme="dark"] .tier-board .char` 로 등급 배색 변수를 다시 입힘 |
| **다크: 노란 버튼 글자가 파랑**(헤더 로그인·티어표 만들기·홈 제작하기) | `[data-theme="dark"] a`(0,1,1) 가 클래스로 색을 정한 링크 버튼(0,1,0)까지 이김 | `:where([data-theme="dark"]) a` 로 구체성 0 — 색 안 정한 링크의 기본값만 담당. 이 변경으로 드러난 2곳(알림 패널 "전체보기", 홈 행운 "자세히 보기")은 다크 색 직접 지정 |
| 아이디/비번 찾기 탭 두 개가 다 노랗고 선택 탭 글자가 안 보임 | `.login-box button`(노란 채움 버튼)이 `.tab-btn` 보다 구체적 | `.login-box .tab-btn` 으로 올려 설계대로 밑줄 탭 |
| 다크: 행운 뽑기 선택 탭 글자가 회색(노란 바탕에 묻힘) | `[data-theme="dark"] .luck-tab` 이 `.active` 보다 구체적 | 다크 `.luck-tab.active` 글자색 복구 |
| 다크: 꾸미기 패널 선택 버튼·랜덤 뽑기 배팅 옵션 선택 표시가 사라짐 | 다크 규칙이 `.is-on`/`.is-active` 와 구체성 같고 뒤에 있음 | 다크 선택 상태 규칙 추가 |
| 다크: 포커 "♣ 클로버" 안내 글자 안 보임 | 카드용 검정을 페이지 바탕 위 칩에도 씀 | 다크에서 칩만 밝은 글자 |
| 라이트: 메이커 검색창·✕ 버튼·다중 선택 안내가 흰 바탕에 흰 글씨 | 검은 풀 상자 기준으로 칠했는데 실제론 페이지 바탕 위에 있음 | 테마 토큰(`--input-bg`·`--text-*`·`--brand-strong`) |
| 다크: 관리자 페이지 번호 버튼 글자 안 보임 | 스타일 없이 브라우저 기본 버튼 | `.pagination button` 테마 토큰으로 명시 |
| 비활성 "보기를 골라주세요"·"걸고 승부하기" 버튼 윤곽이 사라짐 | 비활성 바탕이 카드/페이지 바탕과 거의 같음 | 테두리 추가 |
| 흐린 글자(날짜·안내·빈 목록) 전반 3.4:1 | 라이트 `--text-muted` #8a8b91 | **#6e6f76**(흰 바탕 4.9:1). 고정 회색(#999·#94a3b8·#555·#ccc)도 토큰으로 |
| 앰버 바탕 흰 글자 2.1:1 (홈 행운 뽑기·이벤트 참여·고정·배팅 옵션) | — | 사이트 공통 앰버 버튼처럼 짙은 대비색 |
| 연한 앰버 바탕 앰버 글자 3:1 (로그인 필요 안내·신고 버튼)·공지 카테고리 뱃지 | — | `color-mix()` 로 본문색을 섞어 라이트는 짙게·다크는 밝게 |
| 관리자 "공지 등록" 흰 글자 2.5:1 | #10b981 | #059669 |

## 남겨둔 것 (의도)

- 비활성 버튼의 흐림(opacity) — 눌리지 않는다는 표시
- 해/달·📌·👤 등 이모지 — 글자색과 무관하게 컬러로 그려짐
- 공지 편집 툴바 버튼 — 테두리 없는 텍스트 버튼이 원래 디자인(글자는 잘 보임)
- 1등급 보드의 카드 칸(#111)과 보드(#000) — 등급 고유 배색
