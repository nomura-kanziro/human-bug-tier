# 커밋 요약 — 디자인 고도화 1차 (서체 · 디자인 토큰 · 인증 화면 · 게시판 · 행운 뽑기)

## 개요

"지금 상태에서 더 세련되게"라는 요청으로 진행한 전역 디자인 정리. 화면마다 색·모서리·
그림자·서체가 제각각이던 것을 **theme.css 토큰 한 곳**으로 모으고, 그 토큰을 전 페이지에
입히는 얇은 마감 층(`design-system.css`)을 새로 뒀다. 그 위에서 가장 낡아 보이던 세 화면
(인증 / 게시판 / 행운 뽑기)을 다듬었다.

작업하면서 발견한 **전역 CSS 충돌 3건**(아래 "곁다리로 고친 것")도 함께 고쳤다.

## 주요 구현 내용

### 1. 서체 — 지정만 하고 안 불러오던 폰트

CSS 는 `font-family: "Noto Sans KR"` 이라고 적어놨는데 어디서도 그 폰트를 로드하지 않아,
설치돼 있지 않은 PC 에서는 브라우저 기본 고딕으로 보이고 있었다. 게다가 로그인·회원가입·
관리자 로그인은 `font-family: sans-serif` 라 같은 사이트 안에서 서체가 갈렸다.

`index.html` 에서 Pretendard(dynamic-subset — 필요한 글자 파일만 받아 한글인데도 가볍다)를
불러오고 `--font-sans` 토큰으로 통일했다. CDN 이 막히면 시스템 폰트로 자연스럽게 내려간다.
제목은 자간을 -0.025em 으로 좁히고 `word-break: keep-all` 로 한글이 단어 중간에서 끊기지
않게 했다 — 같은 내용이라도 훨씬 단단해 보인다.

### 2. 디자인 토큰 (`theme.css`)

색만 있던 토큰에 **서체·모서리(5단계)·그림자(3단계)·강조색·초점 링·전환 곡선**을 추가했다.
강조색은 게시판(#ffc400)·행운 뽑기(#f59e0b)·커스텀 메이커 골드가 제각각이던 것을
`--brand`(앰버) 한 갈래로 모았다. 링크는 계속 파랑(`--link-color`).
그림자·강조색은 다크에서 값이 따로 필요해 `[data-theme="dark"]` 에 별도 정의를 뒀다.

### 3. `design-system.css` — 전 페이지 공용 마감

페이지 CSS 를 하나씩 고치지 않고도 전부에 적용돼야 하는 것만 모았다(그래서 `main.jsx`
**맨 마지막** import). 서체 통일, `:focus-visible` 강조색 링(키보드 이동 시에만),
선택 영역 색, 라이트 모드 스크롤바(지금까지 다크만 손봤음), 버튼 공통 눌림 반응,
`prefers-reduced-motion` 존중.

### 4. 인증 화면 — 중복 4벌을 하나로

로그인·회원가입·계정찾기·관리자 로그인은 이미 `AuthShell.jsx` 하나를 공유하는데, CSS 는
네 파일이 **같은 껍데기를 각자 복사**해서 갖고 있었다. 그래서 한쪽만 고치면 다른 쪽이 그대로
남았고, 실제로 이번에 로그인만 고쳤더니 늦게 로드되는 `admin-login.css` 의 옛 규칙
(`.login-box h2 { color: #fff }`)이 이겨서 **제목이 흰 배경에 흰 글자로 사라지는** 일이 났다.

공용 껍데기를 `auth-shell.css` 하나로 합치고 AuthShell.jsx 가 직접 불러오게 했다.
페이지 전용 UI(계정찾기의 탭)만 `auth-find.css` 에 남겼다. 그 위에서:

- 오른쪽의 **빈 파란 사각형**(순수 장식, 내용 없음)을 짙은 그래파이트 + 앰버 글로우 패널로
  바꾸고 로고·사이트 이름·한 줄 소개를 넣어 표지 역할을 하게 했다.
- 카드에 둥근 모서리·테두리·방향성 있는 그림자(예전엔 `0 0 30px rgba(0,0,0,.6)` 이라 사방으로
  번져 보였다), 입력창 폭 240→280px, 로그인=채운 버튼 / 회원가입=테두리 버튼으로 주·보조 구분.
- `h2` 에 인라인 `style="color:#000"` 이 박혀 있어 다크에서 안 보이던 것을 제거하고 토큰으로.

### 5. 게시판

- **검색창이 라이트 모드에서 검정 막대**였다(`background:#1a1a1a` 고정). 테마 토큰으로 교체.
- **카드가 라이트 모드에서도 검정**(`#1f1f1f` 고정)이라 흰 배경 위에 어두운 카드가 늘어서
  있었다. 표면 토큰 + 그림자로 바꾸고, 제목 글자색도 `#fff` 고정이라 흰 카드에서 안 보일 뻔한
  것을 함께 고쳤다.
- 제목 길이에 따라 들쭉날쭉하던 카드 높이를 flex 로 맞춰 조회·추천 줄이 항상 카드 밑면에 붙게 했다.
- 검색·글쓰기가 똑같은 노란 버튼이라 주 동작이 구분되지 않던 것을 검색은 보조 톤으로 내렸다.

### 6. 행운 뽑기

얇은 밑줄 탭 → 알약 스위치, 뽑기 버튼에 그림자·hover, 확률표 행 간격/hover, 결과 카드·기록
목록을 표면 토큰으로. 비활성 버튼은 색을 빼 "지금 못 누른다"가 보이게 했다.

## 곁다리로 고친 것 — 전역 CSS 충돌 3건

Vite 가 모든 CSS 를 한 파일로 번들하기 때문에, 흔한 이름의 전역 선택자는 다른 페이지까지
넘어간다. 이번에 셋을 찾아 범위를 좁혔다.

| 증상 | 원인 | 조치 |
|------|------|------|
| 홈 공지 본문이 가운데 정렬 | `contact_us.css` 의 전역 `.desc { text-align:center }` | `.inquiry-page .desc` 로 축소 |
| 게시판 검색창에 흰 2px 테두리 | `admin-manage.css` 의 **ID 선택자** `#search-input`(클래스보다 우선) | `.search-group #search-input` 로 축소 + 게시판 id 를 `board-search-input` 으로 변경 |
| 로그인 제목이 안 보임 | `admin-login.css` 의 `.login-box h2 { color:#fff }` 가 늦게 로드돼 승리 | 껍데기 CSS 통합(위 4번) |

## 테스트 체크리스트 (`:5000`)

1. 홈·티어표·게시판·행운 뽑기·공지·로그인을 **라이트/다크 둘 다** 확인 — 글자 안 보이는 곳 없음
2. 게시판: 검색창이 배경과 구분되고, 카드가 테마를 따르며 높이가 고르게 맞는지
3. 로그인/회원가입/계정찾기/관리자 로그인 네 화면이 **같은 모양**인지, 모바일(390px)에서 브랜드
   패널이 숨고 폼이 한 단으로 쌓이는지
4. 커스텀 메이커·문의·마이페이지에 회귀 없는지(드래그·업로드 동작 포함)
5. Tab 키로 이동할 때 강조색 초점 링이 보이는지

## 남은 것 (2차 후보)

- 홈 퀵카드 3개가 같은 로고 아이콘을 써서 서로 구분이 약하다
- 공지 카드의 노란 배경(`#fffbeb`)이 새 앰버 강조색과 미묘하게 어긋난다
- 티어표 페이지 상단 네비게이션(1~9티어 알약)은 아직 옛 스타일
- 나머지 페이지(문의·공지 상세·관리자)는 이번 범위 밖 — 토큰만 깔려 있고 개별 마감은 미적용
