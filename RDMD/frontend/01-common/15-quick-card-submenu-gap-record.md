# 커밋 요약 — 메인 화면 퀵카드(커스텀 메이커·행운 뽑기) 하위 링크 간격

## 요청

> 메인 화면 퀵 버튼 중 커스텀 메이커, 행운 뽑기 안에 나열된 버튼들이 너무 다닥다닥 붙어 있는데 위아래 간격 좀 떨어트릴 수 있어?

## 원인

퀵카드 3개(티어표·커스텀 메이커·행운 뽑기) 중 **티어표**만 하위 링크를 그리드(`.sub-grid`, `gap: 8px`)로 그리고,
**커스텀 메이커·행운 뽑기**는 `<Link>` 를 그냥 세로로 쌓는 `.sub-menu` 컨테이너를 쓴다. `.sub-menu a` 에는 위아래 여백이
전혀 없어서 실측해 보니 링크 하나의 아랫변과 다음 링크의 윗변이 **정확히 같은 좌표(간격 0px)** 였다.

## 조치

`.sub-menu > a + a { margin-top: 8px; }` 를 추가했다 — 형제 링크 사이에만 붙는 선택자라 첫 줄 위치는 그대로이고,
간격 값은 티어표 카드의 그리드 gap과 같은 8px 로 맞췄다. `.sub-grid`(티어표)는 이미 grid gap 이 있어 건드리지 않았다.

## 주요 파일

- `root-cloudflare/src/styles/common.css`

## 확인 (실제 Chrome · CDP)

커스텀 메이커 카드에 마우스를 올려 하위 링크 3개(제작하기/게시판/이벤트)의 실제 좌표를 재서 이전 0px → **8px** 간격으로
바뀐 것을 확인. 행운 뽑기 카드도 라이트·다크 모드로 캡처해 같은 간격을 확인. 모바일(390px, hover 없이 항상 펼쳐진 상태)에서도
동일하게 적용됨을 확인. 헤더 메뉴 회귀 테스트 통과.
