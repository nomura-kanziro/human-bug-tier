# 커밋 요약 — 헤더 드롭다운을 클릭식으로 + 사이드 메뉴 하위 항목 간격 축소

## 요청

> 메뉴바 각 드랍다운 토글 애니메이션은 이제 클릭하면 나오는 거고,
> 안에 active는 간격이 너무 떨어진 것 같은데 조금만 간격을 줄여줄 수 있지?

## 1. 데스크톱 드롭다운: hover → 클릭

예전에는 `.nav-item:hover .dropdown` 순수 CSS 로 마우스만 올리면 열렸다. 이제 `Header.jsx` 가 열린 항목의
인덱스(`deskOpen`)를 들고 있다가 해당 `.nav-item` 에 `.open` 을 붙이고, CSS 는 `.desktop-nav .nav-item.open` 기준으로
펼침·화살표 회전·트리거 강조를 처리한다. 애니메이션(투명도·아래로 4px 이동·화살표 180° 회전)은 그대로다.

| 동작 | 결과 |
|------|------|
| 메뉴에 마우스만 올림 | 열리지 않음(화살표도 안 돎) |
| 메뉴 클릭 | 열림 (`aria-expanded=true`) |
| 다른 메뉴 클릭 | 이전 것은 닫히고 그것만 열림 |
| 열린 메뉴 다시 클릭 | 닫힘 |
| 바깥 클릭 / 다른 헤더 컨트롤 클릭 | 닫힘 |
| `Esc` | 닫힘 |
| 드롭다운 항목 선택 | 이동하고 닫힘 |
| 열린 상태에서 마우스가 벗어남 | 그대로 열려 있음 |

바깥 클릭·`Esc` 리스너는 드롭다운이 열려 있을 때만 붙였다 뗀다. 기존 알림 벨/프로필 패널의 바깥 클릭 로직과는 서로
독립이라(둘 다 `document` click 로 각자 닫음) 상호배타가 자연스럽게 유지된다. 모바일 사이드 메뉴는 원래
클릭 아코디언이라 그대로다.

## 2. 사이드 메뉴 하위 항목 간격

펼친 하위 항목(`.side-dropdown.active` 안)이 한 줄에 **실측 83px** 을 차지해 항목 사이가 너무 떨어져 있었다.
원인은 두 가지가 겹친 것이다.

- 모바일 규칙이 링크에 `min-height: 44px` 를 주는데 `box-sizing` 이 `content-box` 라 위아래 패딩 24px 이
  더해져 **링크 하나가 68px**
- 거기에 `li` 의 `margin: 15px`

하위 항목만 `min-height` 를 풀고 패딩을 `11px 8px 11px 12px`, `li` 간격을 6px 로 줄여 **한 줄 46px**(터치 영역 40px)로
맞췄다. 최상위 토글(티어표/이벤트 …)의 간격은 그대로(83px)다. 햄버거는 데스크톱 폭에서도 보이므로 규칙은
미디어쿼리 밖 `app-shell.css` 에 두었고, 기존 모바일 규칙(`.side-menu ul li a`)보다 명시도가 높게(`.side-menu
.side-dropdown .dropdown li a`) 잡았다.

## 주요 파일

| 파일 | 내용 |
|------|------|
| `root-cloudflare/src/components/Header.jsx` | `deskOpen` 상태, 클릭 토글, 바깥 클릭·Esc 닫기, `aria-expanded` |
| `root-cloudflare/src/styles/Header_Footer.css` | `:hover` → `.desktop-nav .nav-item.open` (펼침·화살표), 설명 주석 문구 수정 |
| `root-cloudflare/src/styles/app-shell.css` | 트리거 강조를 `.open` 기준으로, 사이드 메뉴 하위 항목 간격 |

## 확인 (실제 Chrome · CDP, 실제 마우스/키보드 입력)

- hover 만으로는 열리지 않음 · 클릭 열림 · 다른 메뉴 클릭 시 교체 · 재클릭 닫힘 · 바깥 클릭 닫힘 · Esc 닫힘 ·
  항목 선택 이동+닫힘 · 마우스가 벗어나도 유지 · 다크 모드 동작
- 사이드 메뉴 하위 항목 간격 83px → **46px**, 터치 영역 40px, 최상위 토글 83px 유지, 1280px 폭에서 연 사이드 메뉴도 동일
- 회귀: 헤더 메뉴 구성/폭별 레이아웃 테스트, 이벤트 페이지 테스트 27건 통과

알려진 한계: 터치 기기에서 데스크톱 폭(769px 이상)으로 볼 때는 hover 가 없어 예전 방식이 오히려 불편했는데, 클릭식이라
이쪽은 좋아진다. 키보드 화살표 이동(메뉴 항목 간 ↑↓)은 아직 없다.
