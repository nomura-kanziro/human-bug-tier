# 사이드 메뉴 계정 영역 + 모바일 헤더 축소 (1.0.2)

## 요청

> 사이드 메뉴(`side-menu`): 비회원이면 맨 밑에 로그인 버튼, 로그인 상태면 맨 밑에 프로필 보기·로그아웃 등.
> 모바일은 헤더에서 로그인·후원 부분 비중이 커서 크기를 줄이고, 테마 설정·메뉴 버튼도 줄인다(모바일 기준으로만).

- `f84b446` (2026-10-02) feat(header): 사이드 메뉴 하단 계정 영역 + 모바일 헤더 버튼 크기 축소
- `chore(footer): 사이트 버전 표시 1.0.1 → 1.0.2`

## 사이드 메뉴 계정 영역 (`Header.jsx` `SideMenuAccount`)

| 상태 | 표시 |
|---|---|
| 비로그인 | 안내 한 줄("로그인하면 게시판·행운 뽑기·이벤트 기록이 저장돼요.") + **로그인** 버튼 |
| 로그인 | 프로필 사진·닉네임·메일, 버튼 **👤 프로필 보기**(`/my-page`) · **📋 내 게시글**(`/board?search=@닉네임`) · (관리자만) **🛠 관리하기**(`/admin`) · **로그아웃** |

- 항목·동작은 헤더 프로필 드롭다운(`UserProfileMenu`)과 같게 맞췄다. 프로필 사진 변경은 파일 선택 창이 열리는 동작이라 드롭다운·마이페이지에만 둔다.
- 메뉴 항목을 누르면 사이드 메뉴를 닫고 이동한다(`onNavigate`). 메뉴 목록 `<ul>` 에는 `side-menu-list` 클래스를 붙여 계정 영역이 항상 맨 아래에 오게 했다.

## 모바일 헤더 축소 (768px 이하만)

| 요소 | 변경 |
|---|---|
| 로그인 버튼 | 패딩 6×10(480px 이하 6×8), 글자 12px, 줄바꿈 금지 |
| 후원(커피) 버튼 | 32~34px |
| 테마 스위치 | 40×22 → **32×18**(손잡이 14px, 이동 거리 14px) |
| 메뉴(햄버거) 버튼 | 축소, ✕ 로 바뀔 때 선 이동 거리 6px 에 맞춰 조정 |

- **함정**: `app-shell.css` 가 `Header_Footer.css` 보다 나중에 불러와져 로그인 버튼의 데스크톱 패딩이 모바일 규칙을 덮어쓰고 있었다 → 모바일 크기는 `app-shell.css` 에서 정한다.
- 변경 파일: `Header.jsx`, `Header_Footer.css`, `app-shell.css`, `theme.css`.

## 버전

푸터 `Footer.jsx` 의 `SITE_VERSION` 을 1.0.1 → **1.0.2**.
