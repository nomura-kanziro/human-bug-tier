# 커밋 요약 — 헤더 메뉴 확장(3개 → 5개): 이벤트 독립 + 공지·소식 신설

## 요청

> 헤더에 메뉴바 목록을 좀 더 추가했으면 하니 그거 작업해줘.

## 왜 늘려야 했나

작업 전 상단 메뉴는 **티어표 / 커스텀 메이커 / 행운 뽑기** 3개뿐이었고, 그 결과

- **공지사항·새 소식·문의하기는 헤더에서 갈 수가 없었다.** 푸터와 홈 화면에만 링크가 있어서
  다른 페이지를 보고 있으면 맨 아래까지 내려가야 했다.
- **이벤트가 "커스텀 메이커" 드롭다운 안에** 들어가 있었다. 직전 커밋(`dd17575`)에서 이벤트 페이지를
  만들며 임시로 넣어 둔 자리인데, 티어표 제작과는 성격이 달라 찾기 어려웠다.

## 바뀐 구성

```
[로고] 티어표▼  커스텀 메이커▼  이벤트▼  공지·소식▼  행운 뽑기▼        [테마·후원·로그인·햄버거]
```

| 메뉴 | 항목 | 비고 |
|------|------|------|
| 티어표 | 1티어 … 9티어 | 그대로 |
| 커스텀 메이커 | • 제작하기 / • 게시판 | **이벤트를 뺐다** |
| **이벤트** (신설) | • 매일 간단 퀴즈 / • 티어표 공개 / • 메모리 게임 | 이벤트 페이지의 해시 탭(`/event#quiz`, `#showcase`, `#memory`)과 1:1 |
| **공지·소식** (신설) | • 공지사항(`/notice/all`) / • 새 소식(`/notice/news`) / • 문의하기(`/inquiry`) | 헤더에서 처음 노출 |
| 행운 뽑기 | • 오늘의 행운 티어 / • 행운 티어 포커 / • 랜덤 뽑기 | 그대로 |

메뉴 정의(`MENUS`)는 데스크톱 드롭다운과 모바일 사이드 메뉴가 함께 쓰므로, 배열 한 곳만 고치면
**모바일 아코디언에도 같은 5개가 그대로 반영**된다.

## 좁은 데스크톱에서 헤더가 넘치던 문제

메뉴가 5개가 되자 **769~790px 구간에서 헤더 오른쪽(테마 토글·후원·로그인·햄버거)이 화면 밖으로
17px 밀려 가로 스크롤**이 생겼다. 폭별로 실측해 확인한 값:

| 폭 | 메뉴 오른쪽 끝 | 우측 그룹 시작 | 결과 |
|----|----------------|----------------|------|
| 800px | 483 | 483 | 정상 |
| 780px | — | — | `.header-right` 가 771 (뷰포트 765) → 넘침 |
| 769px | — | — | 넘침 17px |

768px 이하는 어차피 `.desktop-nav` 가 숨고 햄버거+사이드 메뉴로 넘어가므로, **769~1024px 구간에서만**
메뉴 간격·좌우 여백·글자 크기를 조금 줄이는 규칙을 `app-shell.css` 에 추가했다
(`gap 8→2px`, `padding 8/12→8/8px`, `font-size 15→14px`, `margin-left 15→8px`).
메뉴를 숨기거나 줄이지 않은 이유는 이 구간만 넘기면 되기 때문이다.

## 덤으로 고친 것 — 홈의 "이벤트 (준비 중)"

홈 퀵카드(커스텀 메이커)에 `• 이벤트 (준비 중)` 비활성 항목이 남아 있었다. 이벤트는 이미 열렸으므로
실제 링크(`/event`)로 바꿨고, 그러면서 쓰이지 않게 된 `Soon` 헬퍼를 제거했다
(헤더 쪽 `item.soon` 처리는 `Header.jsx` 에 그대로 있다).

## 주요 파일

| 파일 | 내용 |
|------|------|
| `root-cloudflare/src/components/Header.jsx` | `MENUS` 3개 → 5개 (이벤트 독립, 공지·소식 신설) |
| `root-cloudflare/src/styles/app-shell.css` | 769~1024px 구간 메뉴 여백·글자 축소 |
| `root-cloudflare/src/pages/Home.jsx` | 퀵카드 "이벤트 (준비 중)" → 실제 링크, `Soon` 제거 |

## 확인 (실제 Chrome · CDP)

- **폭 13종**(1920 / 1600 / 1440 / 1280 / 1100 / 1024 / 950 / 900 / 850 / 800 / 790 / 780 / 769):
  메뉴가 우측 버튼·로고와 겹치지 않고 가로 스크롤 0
- 드롭다운 5개가 1280px 화면 안에 모두 들어옴(가장 오른쪽 "행운 뽑기" 오른쪽 끝 824px)
- 실제 클릭 이동: 이벤트>메모리 게임 → `/event#memory` (탭이 실제로 열림), 공지·소식>문의하기 → `/inquiry`,
  >새 소식 → `/notice/news`, >공지사항 → `/notice/all`
- 모바일 390px: 데스크톱 메뉴 숨김, 사이드 메뉴 5개, 아코디언(이벤트) 펼침 후 이동 시 메뉴 닫힘
- 라이트/다크 드롭다운 캡처 대조
- 회귀: 이벤트 페이지 브라우저 테스트 27건 재통과

알려진 것: 모바일에서 홈 `.quick-card` 가 1px 반올림 넘침을 내는데, 메뉴를 열기 전에도 같은 값이라
이번 변경과 무관하다.
