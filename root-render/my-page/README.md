# 마이페이지 (my-page)

로그인 유저 전용 요약 페이지. 게시글 통계는 기존 API 조합, 행운 뽑기 통계는 `LuckProfile`(적립형 포인트 포함) 기준으로 보여준다.

진입점: 헤더 프로필 아이콘 클릭 → 드롭다운(`#user-profile-panel`) → "마이페이지"

## 파일

| 파일 | 역할 |
|------|------|
| `my-page.html` | 프로필 헤더 + 통계 5칸(게시글·좋아요·뽑기횟수·최고등급·포인트) + 게시글/뽑기 최근 목록 |
| `my-page.css` | 페이지 전용 스타일. `common.css` 미수정 |
| `my-page.js` | 데이터 로딩·렌더. 비로그인 시 로그인 페이지로 리다이렉트 |

## 데이터 소스 (전부 기존 API 재사용/소폭 확장)

| 항목 | API | 비고 |
|------|-----|------|
| 작성한 게시글 목록·수 | `GET /api/tierlists?author=&mine=true` | `mine=true` 는 이 기능을 위해 추가한 옵션 — 본인 소유일 때만 비공개 글도 포함 |
| 받은 좋아요 합계 | 위 응답의 `likeCount` 클라이언트 합산 | 별도 API 없음 |
| 총 뽑기 횟수·최고 등급·행운 포인트 | `GET /api/luck-draw/stats` | `LuckProfile`(누적 카운터) 기준 — 이력이 5건으로 잘려도 정확 |
| 최근 뽑기 기록 | `GET /api/luck-draw/history?page=1` | 최근 5건까지만 존재(자동 삭제 정책) |

## 권한

| 동작 | 비로그인 | 로그인 |
|------|:---:|:---:|
| 페이지 접근 | X (로그인 페이지로 리다이렉트) | O |
| 비공개 글 포함 조회 | - | O (본인 글만) |

## 체크리스트 (수동 테스트)

```
1. 비로그인 상태로 /my-page/my-page.html 접근 → user_login/login.html 로 리다이렉트
2. 로그인 → 마이페이지 → 통계 5칸(게시글/좋아요/뽑기횟수/최고등급/포인트) 표시
3. 비공개 게시글 작성 후 마이페이지 목록에 🔒 표시로 노출되는지 확인
4. 다른 사람의 마이페이지 URL을 흉내내도(author 조작) 내 토큰으로는 내 글만 나옴 (mine=true 오남용 불가 확인)
5. GitHub Pages(GITHUB_STATIC) → 안내 문구만, API 호출 없음
```

## 하지 않은 것

- 포인트를 실제로 쓰는 상점/랭킹 (지금은 적립·차감만 있는 단순 집계)
- 게시글 목록 페이지네이션 (최근 6개만)
- 다른 사람의 프로필 열람(공개 프로필 페이지) — 이번 범위는 "내 정보"만

`.claude/skills/my-page/SKILL.md`, `.agents/my-page/skill.md` 참고.
